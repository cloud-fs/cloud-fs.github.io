CloudDrive2 Core V1.2.0-beta（Web 3.2.0-beta）

本次更新以 1.1.3 正式版为基准，新增媒体服务器和网页播放器两项主要功能。CloudDrive2 不仅可以管理和挂载网盘，还可以在电脑或 NAS 上统一整理媒体库，并直接在浏览器中观看影片、收听音乐和阅读图书。本轮先发布 Beta，欢迎测试并反馈问题。

一、新增媒体服务器：一台设备整理，多台设备使用

在运行 CloudDrive2 核心服务的电脑、NAS 或其他设备上开启媒体服务器，即可将本地文件及已连接网盘中的电影、剧集、音乐和图书整理为媒体库。扫描、识别和资料管理由服务器统一完成，其他设备连接后直接使用，不必分别扫描同一批文件。

1. 在网页中创建、编辑和扫描媒体库，设置扫描计划、扫描速度和识别选项。优先读取文件夹中已有的 NFO 和图片，也可在线查找名称、简介、演员、海报等资料，或导入 Emby / Jellyfin 媒体库。
2. CloudDrive2 App 1.2.0-beta 及以上版本可发现并配对媒体服务器。支持观看用户、配对设备、远程地址和播放转发设置，也可向兼容 Emby / Jellyfin 的播放器提供媒体库及播放服务。
3. 新增网页版影视界面，提供首页推荐、继续观看、下一集、继续收听、继续阅读、搜索、收藏和人物页面。电影、剧集、音乐和图书可在同一界面中浏览。
4. 支持在网页中识别和编辑影片、专辑及人物资料，按分辨率、HDR、音频、视频编码、字幕等条件筛选，并显示扫描与识别结果的实时变化。私密媒体库和家长控制也可在网页中使用。
5. 支持读取各季的 season.nfo 和季海报，在剧集详情页集中显示各季海报；只有一季的剧集也保留季海报。可选择整季或单集，设置按季跳过片头、片尾。
6. 播放进度和已看状态与服务器同步，在其他设备上可以继续观看或收听。
7. 新增后台 AI 字幕任务：为影片、单集、整季及多段影片识别对白、翻译字幕，并将结果保存在视频旁。支持本地 Whisper 或配置的外部服务，可查看状态和耗时、调整等待顺序、暂停及继续任务。任务不需要播放视频，媒体服务器不提供播放中的实时 AI 字幕。
8. 优化 ARM32 设备上的本地 Whisper 语音识别性能，覆盖 Linux ARM32 和 Android ARM32。Linux ARM32 在 Docker 中运行也可使用这项优化，无需为此增加容器启动参数；实际速度取决于处理器能力和线程设置。

重要提示：低端电视盒子及部分较老的 ARM32 设备，即使使用 Base 模型，本地 Whisper 仍可能很慢；Base 模型的识别准确率也较低。我们强烈建议这些设备使用外部语音识别 API，而不是本地 Whisper 模型。可以使用服务器后台任务，在观看前提前生成字幕。

媒体服务器及网页版影视界面需要服务器账号同时拥有 App Pro 和包含媒体服务器功能的核心会员。核心月度、年度及完整版核心终身会员支持，轻享终身会员不包含。

AI 字幕设置说明：https://www.clouddrive2.com/ai-translation.html

二、新增网页播放器：把音视频解码能力带到浏览器中

网页播放器采用浏览器原生播放与网页端解码相结合的方案，将音视频解封装、解码、字幕和画面处理放到播放设备上。浏览器能够直接播放的内容使用原生能力，其他受支持的内容由网页中的解码器处理，覆盖日常收藏中绝大多数常见音视频格式，显著扩大浏览器原生播放器的格式范围。

无需安装播放器或浏览器插件，也不依赖服务器实时转码。服务器负责提供文件和读取光盘内容，播放设备负责解码；电脑、手机和平板打开网页即可使用。在文件管理中直接点开视频、音乐、光盘镜像或 CUE 整轨即可播放，不必先开启媒体服务器；媒体库中的影片和音乐也使用同一个网页播放器。

1. 视频支持 MKV、MP4、AVI、TS、M2TS、FLV、MPG 等容器，以及 H.264、HEVC / H.265、AV1、VP9、MPEG-2、MPEG-4 等常见编码。音轨支持 AAC、AC-3、E-AC-3、DTS、TrueHD、FLAC、Opus 等格式的兼容播放。
2. 蓝光 ISO 和蓝光文件夹可直接播放正片，支持定位播放、章节、切换音轨和显示字幕，无需预先将正片转换为 MP4。
3. 支持 HDR 和杜比视界影片。兼容的 Safari、系统和显示设备可使用原生杜比视界播放；Chrome / Edge 中的杜比视界 Profile 5 可通过 WebGPU 处理为颜色正确的 SDR 画面。其他播放方式根据设备能力显示 HDR 基础层或转换为 SDR。
4. 支持外挂及文件内的文字字幕、PGS 图形字幕和外挂 ASS / SSA 特效字幕。可查看章节、剧集列表、视频与影片资料，继续播放、切换音轨和字幕，并使用跳过片头片尾、自动播放下一集等功能。
5. 音乐支持 MP3、AAC、FLAC、ALAC、APE、WAV 等常见有损和无损格式，还可播放 DSF / DFF、SACD ISO、CUE 整轨及 DTS 音乐。DSD 在网页中转换为 PCM 播放，SACD ISO 使用立体声区。
6. 新增完整音乐播放器和迷你播放器，显示封面、同步歌词、格式信息、播放队列及 MusicBrainz 专辑和歌曲资料。支持随机播放、循环、睡眠定时和系统媒体控制，浏览其他网页管理页面时音乐可以继续播放。
7. 桌面浏览器中，使用网页解码的多种音乐格式支持无缝连续播放；支持的 Safari / Edge 及系统可使用相应的杜比全景声音乐播放方式。
8. 提供手机和平板布局、iPhone 全屏播放、键盘快捷键及触控操作，播放时可保持屏幕常亮，时间显示可在总时长和剩余时间之间切换。

建议使用 HTTPS 或本机 localhost 地址访问，以便使用 WebCodecs 硬件解码、WebGPU 等浏览器能力。在可信的家庭局域网中，也可在 Chrome 打开 chrome://flags/#unsafely-treat-insecure-origin-as-secure，或在 Edge 打开 edge://flags/#unsafely-treat-insecure-origin-as-secure，将网页管理界面的完整访问源地址（例如 http://192.168.1.20:19798，包含协议和端口，不包含后面的路径）加入“Insecure origins treated as secure”，设为 Enabled 后重启浏览器。此设置只让浏览器将指定地址视为安全上下文，不会加密 HTTP 连接；外网访问仍应使用 HTTPS。详细步骤见下方设置说明。

多线程解码还需要浏览器及跨源隔离支持。实际流畅度和 HDR 效果取决于浏览器、播放设备、显示器及网络。4K HEVC，尤其需要软件解码的杜比视界 Profile 5，对播放设备性能要求较高。

网页播放仍受浏览器能力限制，并非所有格式和设备都支持：DVD、VC-1、RMVB、WMV、WavPack、TTA 等目前不在支持范围内。网页中解码的音频以立体声输出，不提供功放源码直通、原生 DSD / DoP、独占输出或光盘菜单；需要这些功能时可使用对应平台的 CloudDrive2 App。详细支持范围见功能介绍。

文件管理中的普通播放不需要会员；HDR、杜比视界、蓝光 ISO、DSD 和 SACD 等高级播放需要 App Pro，未开通时可限时试播。使用文件管理中的播放器不要求开启媒体服务器。

HTTPS 与浏览器硬件解码设置：https://www.clouddrive2.com/web-player.html#chrome-secure-origin

三、其他网页功能更新

1. 媒体库中的图书可直接打开阅读，支持 EPUB、MOBI、AZW3、CBZ 和 CBR；图片及漫画阅读支持静态和动态 JPEG XL。
2. “任务”中新增网盘请求频率统计，查看各存储账号每秒发送的请求数量。
3. SFTP 添加页面提供“允许旧算法”选项，默认关闭，可按需用于连接旧版服务器。
4. App Pro 的适用范围说明包含网页版。已加载的网页在暂时断网时仍可打开，需要联网的文件、账户及会员查询仍需网络。

四、核心存储与传输改进

1. 减少频繁浏览或备份加密文件夹时的内存增长，改善大量扫描 123 云盘目录时的内存与本地缓存占用。
2. 天翼云盘达到当日上传限额后，重试不再反复读取整个源文件，也不会将限额错误误报为源文件已删除。
3. CloudDrive 到另一台 CloudDrive 的传输，在接收端保存到本地文件夹时，发送端也会显示传输进度。
4. 115 开放平台提示访问上限时，暂停该账号的请求并等待恢复，避免持续重复请求。
5. 修复通过 CloudDrive WebDAV 服务用较短文件覆盖较长文件时，文件末尾仍保留旧内容的问题。
6. 清理云端已删除文件及文件夹的本地目录缓存记录；连续短时读取文件时，下载任务、数量和速度也能反映正在进行的读取。
7. 安全性更新。
