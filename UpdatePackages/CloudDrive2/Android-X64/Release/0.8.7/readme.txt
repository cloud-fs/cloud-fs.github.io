V0.8.7(Web1.6.11.0)

1. 增加跨网盘移动功能：在原有跨网盘复制的基础上，增加跨网盘移动功能，去掉web界面的复制按钮，点击移动/复制按钮，选择目的文件夹后可选择是移动还是复制，跨网盘移动将会在全部文件上传成功后删除源网盘的文件和目录。
2. 系统任务管理增加复制任务管理，显示正在进行的跨网盘复制或者移动任务的状态和进度，可以暂停或取消跨网盘复制/移动任务，在扫描源网盘过程中出现错误也会有相应错误信息显示
3. 增加修改账号邮箱功能，可以在web界面的系统设置中修改账号邮箱，要求修改后的邮箱没有注册过CloudDrive2账号
4. 增加对Windows Arm64系统的原生支持，不再支持Windows 7系统
5. 修复115被风控后正在进行的上传任务可能会一直卡住的问题
6. 修复本地文件夹内部复制功能不支持复制文件夹的问题
7. 其它bug修复和性能改进
