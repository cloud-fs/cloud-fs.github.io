V1.0.11(Web3.0.11)

1. 新增支持添加光鸭云盘，目前仅支持只读模式，支持浏览目录和读取文件，无法创建文件夹、删除文件、重命名、移动、上传文件等操作，支持通过光鸭云盘App扫码登录，后续版本会更新完整功能的光鸭云盘
2. S3未填写存储桶名时浏览账户内全部存储桶，自动改用 ListBuckets（GET /），将每个存储桶显示为顶层文件夹；同时支持路径模式与虚拟主机模式、V2/V4 签名。存储桶列表根目录为只读（不支持创建 / 删除存储桶）
3. 修复连接到某些不支持http range的webdav服务器读取文件可能失败的问题
4. Web：新增多服务器支持，可以连接到其它CloudDrive2的grpc服务，方便用在桌面浏览器远程管理移动设备的CloudDrive
5. 其它bug修复和界面优化
