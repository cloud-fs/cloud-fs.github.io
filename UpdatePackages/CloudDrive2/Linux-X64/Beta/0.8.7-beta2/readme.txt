V0.8.7-beta2(Web1.6.10.5)

1. 增加跨网盘移动功能：在原有跨网盘复制的基础上，增加跨网盘移动功能，去掉web界面的复制按钮，点击移动/复制按钮，选择目的文件夹后可选择是移动还是复制，跨网盘移动将会在全部文件上传成功后删除源网盘的文件和目录。
2. 系统任务管理增加复制任务管理，显示正在进行的跨网盘复制或者移动任务，可以暂停或取消跨网盘复制/移动任务，在扫描源网盘过程中出现错误也会有相应错误信息显示
3. 增加对Windows Arm64系统的原生支持，不再支持Windows 7系统
4. 修复115被风控后正在进行的上传任务可能会一直卡住的问题
5. 其它bug修复和性能改进
