V0.9.11-beta(Web2.1.2.0-beta)

1.  支持从网盘下载强制使用http代替https，在低性能设备上用http下载可以显著降低CPU占用，提高下载速度。该选项默认关闭，可以在网盘设置界面打开http下载开关，目前支持115open、123网盘、百度网盘、天翼云盘、迅雷云盘
2. Android APK版支持自升级，需要能访问github获取最新版本，目前版本需要手动安装，从下个版本开始可以自动检测下载升级APK
3. 修复Android APK版本通过SAF访问网盘时，某些应用播放大文件视频失败的问题
4. 改进WebUI文件属性栏图片的元数据显示，加载速度更快，增加显示图片分辨率等信息
5. 改进WebUI文件夹导航栏(breadcrumb)，增加下拉选择隐藏的目录层级
6. 其它性能改善、bug修复和界面优化
