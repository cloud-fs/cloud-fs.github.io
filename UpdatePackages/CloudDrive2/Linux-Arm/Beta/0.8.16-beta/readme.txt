V0.8.16-beta(Web1.6.18.0)

1. 移除对115网盘的支持，请115网盘用户全部迁移到115open，如需保持挂载的115网盘目录，可以在移除115、添加115open之后重命名115open文件夹为老的115目录名
2. 115open支持离线下载功能
3. 115open支持网页授权，网页授权比二维码授权更安全，推荐使用。
4. 修复115open的一些可能的bug
5. 在线更新功能增加对下载后的安装包进行校验，校验失败会重新下载，避免更新失败
6. web界面点击重命名按钮后的重命名输入框根据原文件名自动调整宽度
7. macos的挂载管理支持修改uid/git/权限，支持修改挂载的盘符类型
