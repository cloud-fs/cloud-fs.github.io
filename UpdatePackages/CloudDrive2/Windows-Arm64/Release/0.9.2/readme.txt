V0.9.2(Web2.0.0.0)

1. 全新设计的WebUI 2.0版，界面更美观，对移动设备支持更好，新增多项新功能，包括性能监控、瀑布流风格文件浏览器、web界面内播放视频支持加载同目录下srt和vtt格式的字幕文件等。对WebUI 2.0版有任何问题和建议请及时反馈，将会在后面的版本中持续改进。由于新版本WebUI框架变化较大，从旧版本升级后如果界面显示有问题请清空浏览器缓存后重新加载。
2. 修改账户邮箱需要先向原邮箱发送验证码，填入正确验证码后才能修改，Web2.0.0.0以上版本支持发送和输入验证码，老版本不再支持修改邮箱操作
3. 提高跨网盘传输无法秒传时边下载边上传的传输速度
4. 修复WebDAV客户端上传文件对某些WebDAV Server的兼容性问题
5. 每个Webhook请求最多能携带的文件变更通知条数从10改为100，用户也可以通过设置环境变量MAX_FILE_NOTIFIES_PER_WEBHOOK_REQUEST自己修改这个值
6. 其它bug修复和性能改进
