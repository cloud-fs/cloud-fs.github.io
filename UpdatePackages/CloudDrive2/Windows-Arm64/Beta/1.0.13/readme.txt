V1.0.13(Web3.0.13)

1. 多网盘备份增加全量扫描资源占用控制功能：1) 默认并发备份扫描数为1，可以在备份页面修改最大并发数，超过的备份全量扫描会排队等待; 2) 可以设置上传任务队列上下限，当上传任务数超过设置的上限时，扫描任务会暂停等待，当上传任务数回落到设置的下限时，扫描任务自动恢复，避免因扫描大文件造成太多上传任务堆积，默认为不限制，可以在备份页面修改
2. 跨云盘复制时，可在系统设置下载上传页面设置是否在计算哈希阶段将下载的数据保存到临时文件，上传时将无需再次下载源文件，复制完成后临时文件自动删除，该选项默认为关闭
3. Windows版修复在系统文件管理器对挂载盘图片编辑时可能出错，执行图片旋转后缩略图不自动刷新的问题
4. 修复Web界面实时显示的任务数可能不准确的问题
5. Web界面修复把本地文件拖动到根目录会产生一个无法完成的上传任务，并且创建一个无法删除的文件的问题
