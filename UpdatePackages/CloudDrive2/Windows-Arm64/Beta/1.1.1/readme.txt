CloudDrive2 Core V1.1.1(Web3.1.1)

1. 新增压缩包文件夹。 ISO、zip、7z、RAR、tar 和 SACD ISO 文件不用下载，右键选择"作为文件夹打开"即可浏览，里面的视频和音乐可以直接播放，SACD ISO 显示为 DSF 文件。压缩包文件夹是只读的。此功能默认关闭，在"设置 → 压缩包文件夹"中开启。压缩包文件夹是核心 Pro 功能，轻享终身版用户也可以使用。详细说明见 https://www.clouddrive2.com/archive-folders.html
2. 下载链接可以要求签名。 系统设置中新增"下载链接需要签名"，默认关闭。开启后，在其他设备上打开下载链接时，链接必须带有签名，只知道文件路径的人无法直接下载文件；CloudDrive 提供的下载链接会自动带上签名，在本机打开链接不受影响。开启前保存的链接（例如 .strm 文件中的链接）在其他设备上将无法使用，需要重新复制
3. 网页版增加帮助链接。 各功能页面可以直接打开官网上对应的使用说明
4. 修复 WebDAV 上传出错后，服务器上留下 .clfstmp 临时文件的问题(#592)。 WebDAV 服务暂时出错时，现在会重试上传；放弃上传后会重试删除临时文件
5. 修复覆盖百度网盘上的已有文件后，网盘中同时留下旧文件和一个带时间的副本的问题(#593)。 以前已经产生的带时间的副本需要手动删除
6. 修复 Webhook 配置有错误时的问题。 有错误的配置不再被保存，原来的 Webhook 继续工作
7. 安全性更新

说明：

已知问题（1.1.0 中已存在，尚未修复）：单向备份中同时打开"从目标同步删除"、并把删除规则设为"移到历史文件夹"时，目标文件夹中的 .clfs_history 文件夹本身会被当成多余内容再次移入历史文件夹，每扫描一次多嵌套一层。修复之前请不要同时使用这两个选项。
