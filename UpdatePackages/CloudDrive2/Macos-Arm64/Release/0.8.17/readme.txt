V0.8.17(Web1.6.20.0)

1. 当多个115open通过CloudDrive的云端账号同步多处使用时，改为由CloudDrive服务器统一刷新访问令牌，以彻底解决115open多处使用时各种可能的token失效的问题。同一个CloudDrive账号下的所有运行的CloudDrive请都升级到0.8.17，否则可能会出现115opentoken失效的问题，当出现token失效问题时，请重新授权。注意：使用该功能意味着你同意新版的CloudDrive用户许可协议，新的用户许可协议授权CloudDrive可在必要时在云端加密存储和使用用户的刷新令牌和访问令牌，新的协议完整文本见： [CloudDrive隐私与使用条款](https://www.clouddrive2.com/eula.html)
2. 迅雷云盘增加转存迅雷分享链接功能，使用该功能需要先确保web版本时1.6.20.0，并且重新授权一次迅雷云盘
3. 修复个别情况下机器重启后多云盘备份的配置可能丢失的问题
4. 修复跨网盘复制或者移动不支持0字节文件复制移动的问题
5. 修复上传任务管理里总字节数和已完成数显示的是当前页统计数据而不是所有任务统计数据的问题
6. 其它bug修复和性能改进
