V0.8.6(Web1.6.9.1)

1. 改进和完善115网盘跨设备文件同步功能，同时为避免跨设备文件同步可能造成多终端同时访问115引起不必要的风控，自动跨设备同步功能默认关闭，如需自动同步，可以在115的文件夹属性页中打开监听网盘事件开关
2. 优化115访问流程，降低被风控的风险，115的MaxQueriesPerSecond默认为1，最大可以设置到2，如果碰到被风控，请调低MaxQueriesPerSecond值
3. 修复115用浏览器cookies登录列文件失败的问题
4. 修复在个别情况下上传文件成功后本地缓存磁盘空间不会立即释放，需要重启服务才能释放的问题
5. 修复个别情况下通过挂载目录向加密文件夹内拷贝文件或者编辑文件失败的问题
6. 为了兼容更多的设备，WebUI框架从.net 9回退到.net 7
7. web界面支持macos下按command键实现多选操作，功能和Windows下用Ctrl键多选相同
8. 其它性能改进、bug修复和界面微调
