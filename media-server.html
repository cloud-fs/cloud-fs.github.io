核心会员 + App Pro

媒体服务器

1.2.0 公开 Beta 测试 · 媒体服务器

电脑或 NAS 上的 CloudDrive2 核心服务可以作为媒体服务器：由它统一扫描你的媒体库，识别影片，获取海报和媒体信息，再提供给你的各台设备。CloudDrive2 应用连接后直接显示服务器上的媒体库，不再自己扫描；Infuse、SenPlayer 以及 Emby 和 Jellyfin 的播放器可以像连接 Jellyfin 服务器一样连接它；在浏览器中也可以浏览和播放。第三方播放器和媒体网页通过服务器转发原文件播放，不会收到网盘直链；CloudDrive2 应用仍可通过本机的同账号网盘播放。服务器不转码。

概览

媒体服务器做什么

没有媒体服务器时，每台设备上的 CloudDrive2 应用各自扫描媒体库，再通过你的云盘共享扫描结果。媒体服务器把这些工作集中到一台一直开着的电脑或 NAS 上，并让 CloudDrive2 以外的播放器也能使用这些媒体库。

谁来使用看到的内容怎样播放会员
连接服务器的 CloudDrive2 应用服务器上的媒体库。识别、收藏、跳过片头片尾、检测媒体信息等操作由服务器完成，所有设备都能看到结果用这台设备自己的 CloudDrive2 从网盘播放每台设备都需要 App Pro
自己扫描的 CloudDrive2 应用本机的媒体库；打开「由服务器扫描」后，扫描结果取自服务器同上每台设备都需要 App Pro
Emby 和 Jellyfin 播放器登录用户可以看到的媒体库，私密媒体库除外通过服务器转发原文件，不提供网盘直链不需要，使用服务器账号的会员
浏览器核心服务网页管理界面中的「媒体」页面在浏览器中播放；不能播放的可以复制链接或下载使用服务器账号的会员

和 Emby、Jellyfin 的不同

  • 识别规则与应用相同：文件夹中的 NFO 和图片优先，缺少的信息从 TMDB、Bangumi、MusicBrainz 和 Open Library 获取；识别词、二级分类、私密媒体库等，与应用的媒体库完全一致。
  • 第三方播放器不接收网盘直链：Infuse、SenPlayer、Emby 和 Jellyfin 播放器以及媒体网页只使用 CloudDrive2 的鉴权播放接口，由服务器转发原文件；播放速度受服务器的网络和处理能力影响。CloudDrive2 应用通过本机的同账号网盘播放时，不占用媒体服务器的转发带宽，见播放方式。
  • 不转码：所有客户端都按原文件播放。需要服务器转码才能播放的客户端，无法播放它不支持的格式。
  • 网盘只读取一次：播放器不用自己扫描网盘，媒体库由服务器按设定的速度读取一次，减少网盘因请求过多而限制账号的情况。
  • 与应用共享：媒体库的设置、识别结果、扫描数据和海报通过你云盘中的「CloudDrive2 Sync」文件夹与 CloudDrive2 应用共享。在应用中修改媒体库，服务器也会更新；反之亦然。

在哪里运行

运行 CloudDrive2 核心服务的电脑、NAS 或 Docker 容器，支持 x86_64、ARM64（aarch64），也提供 ARM32（ARMv7）的 Linux 和 Android 构建；不支持 MIPS。新版标准发行包包含媒体服务器和本地 Whisper，无媒体的旧版兼容构建不包含这些功能。服务器最好一直开着；关机时，已连接的应用显示之前读取的内容。

Mac、Windows 电脑、Android 电视盒子等设备上的 CloudDrive2 应用，也可以把自己的媒体库提供给其他设备，见由应用提供媒体库。

服务器读取的是这台 CloudDrive2 中添加的网盘和本地文件夹，所以媒体所在的网盘要先添加到这台 CloudDrive2 中。海报、人物照片等图片保存在服务器上，图片上限至少 10 GB，请预留足够的磁盘空间。

需要的会员

媒体服务器需要服务器登录的 CloudDrive 账号同时拥有核心会员（月费、年费或终身版，轻享终身版不含）和 App Pro，缺少任何一项都不会打开或扫描媒体库。核心会员到期后，媒体服务器停止提供媒体库，续费后恢复。连接服务器的 CloudDrive2 应用需要在自己的设备上有 App Pro。Emby 和 Jellyfin 播放器以及浏览器使用服务器账号的会员，不需要另外购买。见会员与价格。

开始使用

开启媒体服务器

  1. 登录并添加网盘

    在核心服务的网页管理界面中登录同时拥有核心会员和 App Pro 的 CloudDrive 账号，并添加媒体所在的网盘。登录的账号就是媒体库的所有者。

  2. 准备同步文件夹

    服务器通过「CloudDrive2 Sync」文件夹与应用交换媒体库和扫描结果。在任意一台设备的 CloudDrive2 应用中打开「同步进度」并选择保存位置；保存它的网盘也要添加到服务器的 CloudDrive2 中。还没有在应用中设置过的，可以在打开开关之后，到「媒体库」标签页中选择一个存储，由页面创建这个文件夹。

  3. 打开开关

    在网页管理界面的侧边栏中点「媒体」，再点页面上的「媒体服务器」，在「概览」中打开「媒体服务器」开关。

  4. 添加媒体库

    在应用中创建过的媒体库会自动出现。也可以在「媒体库」中添加。服务器开始扫描，进度显示在「概览」和「媒体库」中。

  5. 连接设备

    在 CloudDrive2 应用中选择这台服务器（见 CloudDrive2 应用），在播放器中添加服务器（见 Emby 和 Jellyfin 播放器），或在浏览器中打开「媒体」页面（见在浏览器中观看）。

页面提示的问题
  • 「此版本的 CloudDrive 不包含媒体服务器」：请更新核心服务。
  • 「媒体服务器需要同时拥有核心会员（月费、年费或终身版）和 App Pro」：账号缺少其中一项时，页面只显示这条提示和会员页面的链接。
  • 「当前账号没有 App Pro，不会打开或扫描媒体库」：媒体服务器除了核心会员，还需要 App Pro。
  • 「当前账号没有包含媒体服务器的核心会员，不会打开或扫描媒体库」：需要月费、年费或终身版会员，轻享终身版不含媒体服务器。
  • 「无法在线检查套餐」：请检查这台服务器的网络连接。
  • 「没有存储包含此账号的 CloudDrive2 Sync 文件夹」：在「媒体库」标签页中创建，或见上面第 2 步。
媒体界面

开启后，可以在网页管理界面的侧边栏底部点「媒体界面」，切换到与应用相同的布局：侧边栏中有首页、收藏、搜索、各个媒体库、媒体库待确认、文件、任务、媒体服务器和设置。点「文件管理器」切换回来。手机浏览器中，媒体界面在页面底部显示标签栏，「媒体服务器」在页面右上角的菜单中。

管理

「媒体服务器」页面

只有核心服务的管理员可以打开这个页面。服务器关闭时只显示「概览」。

标签页内容

媒体库

媒体库与识别

1.2.0 公开测试版读取各季文件夹中的 season.nfo，包括季名、简介、播出日期、评分和图片引用；也支持剧集根目录中的 season01-poster.jpg 等季海报。剧集详情页集中显示各季海报，只有一季时也保留季海报，与整部剧的海报分别显示。

服务器上的媒体库就是这个 CloudDrive 账号的媒体库：在网页上添加或修改，会同步到所有设备；在应用中修改，服务器也会更新。识别和整理的规则与应用相同，详见视频如何识别、刮削与匹配、识别词和二级分类。

编辑媒体库

  • 编辑窗口中的选项与应用的媒体库编辑页相同：名称、类型、文件夹、私密媒体库、在线查找、信息语言、优先使用在线信息、识别时检测媒体信息、无海报时使用视频画面、在媒体旁保存信息和图片、识别词、二级分类，以及「在本服务器上扫描此媒体库」。文件夹用网页的文件选择器从这台 CloudDrive2 中选择。
  • 「列目录速度」（每秒 1 至 10 次或不限制，默认每秒 2 次）和「重新扫描」是服务器自己的设置，不影响你的设备。封面和「在本设备缓存文件」只在应用中设置。
  • 私密媒体库在页面上输入 PIN 之后才显示。解锁后，它们也出现在「媒体」页面的侧边栏和首页中，只对这个浏览器有效，直到你点「锁定」；关闭这个浏览器中所有的 CloudDrive 页面约 10 分钟后自动锁定。PIN 也可以在这个页面上设置、修改或移除，把媒体库设为私密时可以直接设置 PIN。
  • 服务器一次扫描一个媒体库，完成后再扫描下一个。「立即扫描」马上重新读取这个媒体库的文件夹。

由服务器扫描

「扫描和存储」中的「由服务器扫描」默认关闭。打开后由服务器扫描所有媒体库，没有连接服务器、仍然自己整理媒体库的手机、平板和电视会等待服务器的扫描结果，不再自己扫描。打开之后如果在某台设备上设置由它扫描某个媒体库，以那台设备为准。需要设备上打开了「跨设备同步媒体库」和「跨设备同步扫描数据」，见由一台设备扫描。

也可以只让服务器扫描某几个媒体库：在媒体库的编辑窗口中打开「在本服务器上扫描此媒体库」，与应用中的「在本设备上扫描此媒体库」相同。这一行显示现在由哪台设备扫描；「由服务器扫描」打开时，这个开关保持打开、不能更改。点「立即扫描」时，服务器总是马上扫描这个媒体库。

播放位置与已看完

「媒体库」中的「最小续播百分比」（默认 5%）和「最大续播百分比」（默认 95%）用于 Emby、Jellyfin 播放器和网页播放器：播放不到最小百分比就停止时不记录位置，已有的位置也会删除；超过最大百分比时标记为已看完。已看完的视频再次播放，中途停止时会记住位置，已看完的标记保留；拖回开头再关闭，会清除继续播放的位置。CloudDrive2 应用使用自己媒体库设置中的百分比，见媒体库。

AI 字幕

重要提示：低性能设备强烈建议使用外部语音识别 API

电视盒子和部分老旧 ARM32 设备即使启用了 CPU 优化，运行 Whisper Base 模型仍然很慢，生成字幕可能比播放视频耗时更长。Base 模型对影视对白的识别准确度很低，尤其是在有背景音乐或对白不清晰时；速度优化不会提高模型的准确度。

在这些设备上，我们强烈建议使用外部语音识别 API，不建议使用本地 Whisper 模型。见远程 API 设置。

媒体服务器在后台为媒体库中的视频生成字幕，不需要播放视频。它识别视频中的对白，或读取视频自带的字幕，翻译后把字幕文件保存在视频旁边，你的设备和播放器都能使用。服务器不提供播放中的实时字幕。字幕的格式和选项与应用相同，见 AI 字幕翻译。

  • 在「媒体服务器 → AI 字幕」中打开，并选择语音识别和翻译的服务。语音识别可以使用远程服务，也可以在服务器上用 Whisper 完成。1.2.0-beta 标准核心发行包包含本地 Whisper，包括 ARM32 Linux 和 Android 构建；首次使用需要下载模型。无媒体的旧版兼容构建不提供此功能。密钥保存在服务器上。
  • 在影片的详情页点「生成 AI 字幕」，或在媒体库中选择多项后添加。连接服务器的 CloudDrive2 应用添加的视频，也交给服务器生成，使用服务器自己的服务和密钥。
  • 进度在「任务」页面的「AI 字幕」中：可以调整顺序、暂停或取消某个视频，并看到每个视频用了多长时间。分成几段的电影，每一段都会生成。
  • ARM32 Linux 和 Android 核心使用优化的 Whisper CPU 运算。Linux 在处理器支持 NEON 和 VFPv4 时自动启用加速，旧处理器使用兼容实现。在 Docker 中同样自动生效，无需额外的加速参数，见Docker 中的 AI 字幕。
  • 先运行「测试语音识别」，查看 25 秒音频的处理耗时、相对播放速度、使用的线程数，以及使用 CPU 还是 GPU。速度低于 1 倍表示生成字幕所需的时间比播放更长，仍可用于后台生成。实际速度取决于处理器、模型、线程数和可用资源；可比较不同线程数的测试结果，再选择设置。

识别

  • TMDB：服务器上默认开启，不需要自己申请 API 密钥。接口地址默认 api.tmdb.org，在中国大陆可以直接访问；也可以选 api.themoviedb.org 或填写自己的代理地址。TMDB 的图片由服务器获取后交给你的设备和播放器，它们不需要自己连接 TMDB。
  • 待确认：自动识别无法确定的影片，可以在网页的「媒体库待确认」中确认，也可以在应用中确认。选择后服务器马上获取信息，所有设备都能看到。
  • 识别…、编辑元数据…、检测媒体信息：在浏览器中使用时由服务器完成并写入；在连接服务器的应用中识别影片和检测媒体信息，也由服务器完成。
  • AI 辅助识别：默认关闭。选择服务、模型和 API 密钥，以及模型读取的媒体库（私密媒体库和关闭了在线查找的媒体库不在其中）。每天调用模型的次数可以选择或自己填写，也可以不限，默认最多 1000 次。见AI 辅助识别。

从 Emby 或 Jellyfin 导入

在「媒体库」中点「从 Emby 或 Jellyfin 导入…」，登录你的服务器。文件夹位于这台 CloudDrive2 网盘中的媒体库，会成为这里的媒体库，影片、简介和图片、你在那里的观看记录以及人物都从那台服务器读取，不修改那台服务器上的内容。见从 Emby 或 Jellyfin 导入。

清除媒体库数据

删除服务器已读取的条目、详细信息和图片，然后重新读取媒体库。媒体库、识别结果和观看进度都会保留。

应用

CloudDrive2 应用连接服务器

Mac、iPhone、iPad、Apple TV、Apple Vision Pro、Android 手机、平板和电视、Meta Quest 和 Windows 电脑上的 CloudDrive2 应用可以连接媒体服务器。设置在「设置 → 媒体库 → 同步」的「连接媒体服务器」中，需要这台设备上有 App Pro。

找到服务器

  • 同一个 CloudDrive 账号：服务器在同步文件夹中写入自己的地址，登录了同一个账号的设备会自动找到它，显示「在同步文件夹中找到」。点「使用」即可，不需要配对码。
  • 配对码：没有设置同步文件夹或登录了其他账号的设备，点「用配对码配对…」。窗口中列出这个网络中的服务器，也可以输入服务器在家庭网络中的地址，例如 192.168.1.20。配对码在网页的「用户和设备 → 已配对的设备」中点「生成配对码」得到，只能用一次，有效期有限。

使用服务器时

  • 这台设备直接显示服务器上的媒体库，不再自己扫描。已扫描的数据会保留，点「这台设备」改回自己扫描时可以继续使用。
  • 识别、保留匹配、重新查找、检测媒体信息、编辑媒体库、收藏、标记已看和跳过片头片尾的时间都由服务器完成和保存，所有设备都能看到。为某部影片选择的音轨和字幕，也会带到其他设备上。
  • 信息语言设为「跟随界面语言」的媒体库，每台设备以自己的界面语言显示标题和简介：中文界面的手机和英文界面的电视连接同一台服务器，各自看到自己的语言。切换界面语言后，媒体库随即以新的语言显示；服务器还没有这种语言的信息时，会优先获取。
  • 播放时，这台设备用自己的 CloudDrive2 从网盘读取视频，见播放方式。
  • 服务器上设置了用户时，应用会询问「谁在看？」，见用户。

连不上服务器时

应用显示「连不上服务器，正在显示之前读取的内容，每 30 秒重试一次」，可以继续浏览之前打开过的页面。服务器恢复后自动重新连接。离开家时，设备会尝试服务器在同步文件夹中写入的外部地址，见在外使用。

移除设备

在网页的「已配对的设备」中可以看到每台设备的平台、配对方式和最后连接时间，点「移除」后它要重新配对才能连接。在应用中点「移除」则删除这台设备上保存的服务器，需要新的配对码才能再次配对。

版本

服务器需要新版本的应用时，应用会显示「服务器需要更新版本的 CloudDrive 应用」。请让服务器和应用保持最新版本。

由应用提供媒体库

没有一直开着的电脑或 NAS 时，CloudDrive2 应用也可以把这台设备自己扫描的媒体库提供给其他设备：在「设置 → 媒体服务器」中打开「将这些媒体库提供给其他设备」。需要这个账号同时拥有 App Pro 和包含媒体服务器的核心会员。

  • 你的其他设备通过同步文件夹找到它，像连接服务器一样使用；Emby 和 Jellyfin 播放器可以连接它的地址，端口 29798。配对码和已配对的设备也在这个页面上。
  • Mac 和 Windows 电脑在应用运行时提供，包括在后台和菜单栏、托盘中；Android 手机、电视盒子和 Meta Quest 在应用的服务运行时提供，电视盒子最适合；iPhone、iPad、Apple TV 和 Apple Vision Pro 只在应用打开时提供。
  • 正在使用媒体服务器的设备不能同时提供：只有这台设备自己扫描的媒体库才能提供给其他设备。

其他播放器

Emby 和 Jellyfin 播放器

Infuse、SenPlayer 以及 Jellyfin 和 Emby 的播放器可以像连接 Jellyfin 服务器一样连接媒体服务器。播放器不需要自己的会员，使用服务器账号的会员即可。

  1. 添加服务器

    在播放器中添加 Jellyfin 服务器，地址填核心服务网页管理界面的地址，例如 http://192.168.1.20:19798。Emby 播放器添加 Emby 服务器，地址相同。

  2. 登录

    用网页「用户和设备 → Emby 和 Jellyfin 播放器」中显示的用户名和那里设置的「媒体密码」登录；或者用某个用户的名字和他的播放器密码。媒体密码至少 6 个字符，只用于播放器登录，不是核心服务的管理员密码。

  3. 或者用快速连接

    在 Jellyfin 播放器中选择「快速连接」，它会显示一个 6 位数的代码。在网页的「快速连接」中允许它，或输入这个代码。代码 10 分钟内有效。没有设置媒体密码时，播放器只能这样登录。

播放器能做什么

  • 浏览登录用户可以看到的媒体库，私密媒体库除外：电影、剧集的季和集、合集、音乐的专辑和艺术家、图书、二级分类、人物、搜索和筛选。
  • 按原文件播放，包括外挂字幕。服务器不转码，也不限制码率。
  • 播放进度、已看和收藏按登录用户保存，在其他播放器和设备上继续。
  • 支持媒体片段的 Jellyfin 播放器可以跳过片头片尾，时间与应用中设置的相同。

需要注意

  • 需要服务器转码的客户端（例如部分电视上的官方应用）无法播放它们不支持的格式。
  • 为保护网盘链接，第三方播放器播放任何网盘的文件都由服务器转发，不会收到网盘直链；在家庭网络之外，需要打开「为家庭网络之外的设备转发视频」，见播放方式。
  • 从外部连接时，Infuse 等播放器不接受自签名证书，需要使用你自己域名的证书或反向代理，见在外使用。
  • 在家庭网络中，播放器的登录页会列出可以登录的用户：设置了媒体密码的所有者，以及设置了播放器密码的用户。

其他工具

Emby 兼容接口

MoviePilot 等工具可以像连接 Emby 服务器一样连接媒体服务器，读取媒体库中的影片和人物，并补全演员的名字、简介和头像。设置在「用户和设备 → Emby 兼容接口」中，默认关闭，媒体服务器开启时才可用。它与应用中的 Emby 兼容接口相同，但由一直开着的服务器提供。

连接工具

  1. 打开「开启 Emby 兼容接口」。
  2. 点「新建密钥…」，为每个要连接的工具生成一个密钥，并选择它可以读写的媒体库（「全部视频媒体库」或其中几个）；勾选「包括私密媒体库」时，也包括私密媒体库。密钥只显示这一次，请立即复制。
  3. 在工具中把服务器类型选为 Emby，填入页面上列出的服务器地址（核心服务的地址）和密钥。还要求用户登录的工具，用户名填所有者的名字或 admin，密码填媒体密码。

每个密钥显示创建和最后使用的时间，可以更改它的媒体库或移除它。「最近的请求」列出工具最近的请求和服务器的回答，便于检查连接。

其他应用写入的信息

  • 人物的名字、简介、照片和角色名，以及收藏。人物信息优先于 NFO 和 TMDB 显示，所有设备都能看到。
  • 这些信息保存在服务器上，不写入媒体所在的文件夹。「清除其他应用写入的信息」删除它们，密钥保留。
  • 跟随人物简介中的链接：工具为人物写下的只是 TMDB、IMDb 或维基百科的链接时，从这些网站读取简介、生日和照片。链接中的编号会发送给 TMDB 或维基百科。
安全

密钥会出现在工具请求的地址里，请妥善保管。通过这个接口只能读写所选媒体库中的影片和人物，无法访问你的文件和账号。同一个地址一分钟内用错密钥 5 次，要等一分钟才能再试。

浏览器

在浏览器中观看

核心服务网页管理界面中的「媒体」页面是服务器自带的媒体客户端，布局与应用的影视界面相同：电脑上是宽屏布局，手机上是手机布局。以所有者的身份浏览，播放进度和收藏与服务器同步。

页面

  • 首页：精选轮播、媒体库、继续观看、接下来、继续收听、继续阅读，以及每个媒体库的最新内容。
  • 媒体库：海报、缩略图、横幅或列表，图片大小，排序，筛选（播放状态、收藏、分辨率、HDR、声音、视频编码、文件格式、音轨语言、字幕语言、类型、标签、制片公司、状态、分级、年份，见筛选），文件夹，二级分类和合集，选择多项，跳到某页。音乐库按专辑、艺术家和文件夹浏览，图书库按图书、作者、系列和文件夹浏览。
  • 详情页：播放或继续播放、预告片、已看、收藏，版本、视频、音频和字幕的选择，季和集，演员，合集和链接，媒体信息。「识别…」「编辑元数据…」（包括海报、背景图、Logo 和演员照片）、「检测媒体信息」「生成 AI 字幕」「转到媒体库」（打开媒体库并停在这部影片上）和「在文件中显示」（打开文件所在的文件夹，选中并滚动到这个文件；剧集和专辑文件夹打开它自己的文件夹）。
  • 随服务器更新：扫描新找到的影片、识别结果、后来获取的图片、收藏和已看，在打开的页面上直接出现，不需要刷新页面。
  • 搜索、收藏、历史，以及人物、专辑、艺术家、图书、作者和系列的页面。从某个媒体库的页面搜索时，先在这个媒体库中查找，可以切换到全部媒体库；历史中也列出听完的歌曲所在的专辑。人物页可以「识别」和「编辑…」，演员的影片可以像媒体库一样排序和筛选。
  • 音乐在完整的播放器中播放，显示封面、歌词、队列、格式角标和 MusicBrainz 的演职人员；收起后是页面底部的迷你播放器，浏览其他页面时继续播放。图书用网页的阅读器打开（EPUB、MOBI、AZW3、CBZ、CBR），PDF 和文本在浏览器中打开；阅读位置与应用共用。

播放器

「媒体」页面中的影片和音乐用核心服务的网页播放器播放。网页播放器是一项独立的功能：文件管理中的视频、音乐、光盘镜像和 CUE 整轨也用它打开，不需要开启媒体服务器。它能播放的格式、对浏览器和电脑的要求，以及与 App 播放器的对比，见网页播放器。

从媒体库播放时，播放进度和已看与服务器同步，其他设备和 CloudDrive2 App 都能看到；剧集可以跳过片头片尾，播完自动播放下一集。

用 HTTPS 打开

在浏览器默认设置下，网页使用 WebCodecs 硬件解码需要 HTTPS 或本机 localhost 等安全上下文。用 http://局域网地址 打开时，如果音轨不受浏览器原生播放支持，4K HEVC 等视频可能改用软件解码，出现跳帧或播放不流畅；Safari 原生支持的音频格式较多，通常不受这一限制影响。建议使用 HTTPS；也可在 Chrome 和 Edge 中将指定的可信局域网地址设置为安全来源，让该 HTTP 地址使用这些浏览器能力，见在 Chrome 和 Edge 中使用硬件解码。

家长控制

媒体界面中可以设置家长控制的密码，保存在这个浏览器中。锁定时，打开文件、文件管理器、任务、设置、识别、编辑元数据和媒体设置之前要输入密码，「在文件中显示」不显示，只显示不超过最高分级的内容。页面隐藏时和超过自动锁定时间后自动锁定。见家长控制。

浏览器中的设置

「媒体」页面的「设置」只保存在这个浏览器中：每页显示的条目数（50 至 1000，或滚动加载全部）、网格和列表中的图片大小、海报上的画质角标。媒体库的设置按钮打开「媒体服务器」页面中这个媒体库的编辑窗口。

家庭网络

来自私有地址（例如 192.168.x.x、10.x.x.x）和 IPv6 本地地址的连接算作家庭网络。通过运营商的共享地址、Tailscale 等组网工具或公网地址连接的，算作在家庭网络之外。

转发占用的带宽

「为家庭网络之外的设备转发视频」默认关闭。第三方播放器和媒体网页的文件始终经过服务器；在家庭网络之外，关闭此开关就无法播放，打开后会占用服务器的上传带宽，上传速度要高于影片的码率才能流畅播放。CloudDrive2 应用通过本机的同账号网盘或所有者可信设备的网盘链接播放时，不需要转发。

家庭

用户

在「用户和设备 → 用户」中为共用这些媒体库的家人和孩子添加用户。每个用户有自己的播放进度和收藏，只能看到为他选择的媒体库。这个 CloudDrive 账号本身是所有者，所有者的代码就是媒体库的 PIN。最多 32 个用户。

用户的设置

  • 名字、颜色或头像：头像可以是 JPEG 或 PNG 图片，最大 2 MB。
  • 媒体库：选择他能看到的媒体库，或「全部媒体库」（包括以后添加的）。
  • 输入 PIN 后可打开私密媒体库：不选时，这个用户无法打开私密媒体库。
  • 最高分级：不限制、G、PG、PG-13 或 R，以及是否「显示没有分级的内容」。设备自己的家长控制也设置了分级时，以更严格的为准。
  • 代码：4 位数字，可不设。设备选择这个用户前要输入。连续输错 5 次需要等 5 分钟。
  • 播放器密码：可不设，至少 6 个字符。Emby 和 Jellyfin 播放器用这个用户的名字和密码登录。

设备使用哪个用户

  • 在「已配对的设备」中为每台设备选择「所有者」、某个用户或「每次询问」。生成配对码时也可以选择用这个配对码配对的设备使用哪个用户。
  • 设为「每次询问」的设备，打开媒体库时显示「谁在看？」，选择后才显示内容；服务器重启后会再次询问。
  • 快速连接时选择播放器登录为哪个用户。

进度和收藏

用户的播放进度、已看和收藏保存在服务器上，与所有者的分开，不写入所有者的「同步进度」。删除用户时，他的进度、收藏和头像一起删除，使用他的设备改为询问。

外出

在外使用

在家庭网络之外，你的设备通过服务器写入同步文件夹的地址连接它。这些设置在「用户和设备 → 在外使用」中。

让服务器可以从外部访问

  • 路由器端口映射：在路由器上转发 19799 端口（HTTPS），或使用核心服务的 UPnP 端口映射（路由器支持 UPnP 或 PCP 时）。页面显示当前的映射。
  • 外部地址：从外部访问这台服务器的域名或 IPv6 地址，要带协议和端口，例如 https://nas.example.com:19799，最多 8 个。
  • 设备会尝试的地址：页面列出设备在家庭网络之外会尝试的地址。

证书

CloudDrive2 应用在配对时记下服务器的证书，使用核心服务自带的证书也能安全连接。Infuse 等其他播放器只接受受信任的证书：请为你的域名配置证书，或使用反向代理。

为家庭网络之外的设备转发视频

默认关闭。第三方播放器和媒体网页在家庭网络之外播放时必须打开，不限网盘类型，见播放方式。

安全

安全

媒体服务器与文件服务使用同一个端口。下面说明它们如何分开。

  • 设备和播放器只能访问媒体库：配对的设备和登录的播放器得到的凭证只能读取媒体库，不能访问你的文件、WebDAV 和下载链接，也不能管理核心服务。
  • 媒体密码不是管理员密码：媒体密码和播放器密码只用于播放器登录。「媒体服务器」页面只有核心服务的管理员可以打开。
  • PIN 在服务器上检查：私密媒体库的 PIN 不会发送给其他设备，连续输错会暂时锁定这台设备。
  • 配对：配对码只能用一次，连续输错 5 次后，所有未使用的配对码都会失效。移除设备后，它得到的链接也随之失效。
从外部可以访问时

服务器可以从外部访问，而文件下载（/static）不需要签名链接时，页面会提示。请在核心服务的设置中打开「下载链接需要签名」，并为管理员账号设置强密码和两步验证。媒体服务器、你的设备和签名的下载链接不受这个设置影响。

同步文件夹中有服务器的地址和配对信息，你的设备用它们自动配对。能打开这个云盘的人也能读到这些信息。需要撤销时，在「已配对的设备」中点「更换配对密钥」，并移除不认识的设备。

隐私

哪些信息离开服务器

  • CloudDrive 的服务器：不接收媒体库的任何内容，只确认账号的会员。
  • TMDB 和 Bangumi：开启查找时，发送影片的名称和年份。
  • MusicBrainz：开启时，发送专辑的名称、艺术家、条码和目录号，CD 抓轨的各曲时长。
  • Open Library：开启时，用于开启了在线查找的图书库，发送书名、作者和 ISBN。
  • 你选择的 AI 服务：只在打开 AI 辅助识别时，发送所选媒体库中未识别项目在媒体库文件夹以下的路径、文件名，以及从文件中读到的标签、CUE 表、SACD 文本或 OPF。私密媒体库的内容不发送。部分服务可能会用免费套餐下发送的内容训练模型；DeepSeek 将数据存储在中国大陆。
  • 你的 Emby 或 Jellyfin 服务器：只在导入时，用你的登录读取媒体库、影片、人物、图片和你的观看记录，不写入任何内容。
  • MoviePilot 等工具：只在打开 Emby 兼容接口时，持有密钥的工具可以读写为它选择的媒体库中的影片和人物。
  • 你选择的语音识别和翻译服务：只在生成 AI 字幕时。使用远程语音识别时发送视频的声音，翻译时发送识别出的文字或视频自带的字幕。在服务器上用 whisper 识别时，声音不离开服务器。
  • 你的云盘：同步文件夹中保存媒体库的设置、扫描数据、图片包，以及服务器的地址和配对信息；开启「在媒体旁保存信息和图片」或使用「编辑元数据…」时，在影片文件夹中写入 NFO 和图片；AI 字幕生成的字幕文件保存在视频旁边。
  • 你的设备和播放器：看到为它们的用户选择的媒体库、影片信息和图片，以及播放所需的文件路径和鉴权播放地址。第三方播放器不会收到网盘直链。

文件不会被删除。服务器只读取媒体库的文件夹；会写入的只有你开启的「在媒体旁保存信息和图片」、你用「编辑元数据…」保存的内容、AI 字幕生成的字幕文件，以及同步文件夹中的文件。

FAQ

常见问题

媒体服务器需要哪些会员

服务器登录的 CloudDrive 账号需要同时拥有核心会员（月费、年费或终身版，轻享终身版不含）和 App Pro，只有其中一项时不能使用媒体服务器。连接服务器的 CloudDrive2 应用，每台设备都需要自己的 App Pro。Infuse、SenPlayer、Emby 和 Jellyfin 的播放器以及浏览器不需要另外购买。核心会员到期后，媒体服务器停止提供媒体库，续费后恢复。

没有 NAS，可以用电视盒子或电脑当服务器吗

可以。在那台设备的 CloudDrive2 应用中打开「设置 → 媒体服务器 → 将这些媒体库提供给其他设备」，你的其他设备和 Emby、Jellyfin 播放器就能读取它扫描的媒体库。电脑和电视盒子在应用运行时一直提供，iPhone、iPad、Apple TV 和 Apple Vision Pro 只在应用打开时提供。见由应用提供媒体库。

应用中找不到服务器

自动找到服务器需要两边登录同一个 CloudDrive 账号，并且这台设备打开了「同步进度」、能访问保存「CloudDrive2 Sync」的网盘。否则在「设置 → 媒体库 → 同步 → 连接媒体服务器」中点「用配对码配对…」，在网页的「已配对的设备」中生成配对码，选择窗口中列出的服务器或输入它的地址。设备需要能访问核心服务的端口（默认 19798）。

连接服务器后，还要在每台设备上扫描吗

不用。连接服务器的设备直接显示服务器上的媒体库，不扫描，也不在线查询。仍然自己整理媒体库的设备，可以在服务器上打开「由服务器扫描」，直接取用服务器的扫描结果。

播放器可以登录，但 115 网盘中的影片不能播放

第三方播放器播放 115 或其他网盘的文件都由服务器转发，不会收到网盘直链。在家庭网络之外，请在「在外使用」中打开「为家庭网络之外的设备转发视频」；通过 Tailscale 等组网工具连接也算在家庭网络之外。在家庭网络中，请检查服务器本身能否读取文件，以及播放器是否支持该格式。

在外面用 Infuse 连不上

Infuse 等播放器不接受自签名证书。请为你的域名配置受信任的证书，或使用反向代理，再在播放器中使用这个 https 地址。CloudDrive2 应用不受影响。

服务器会转码吗

不会。所有客户端都按原文件播放，解码由播放器和设备完成。第三方播放器始终由服务器转发原文件，播放速度受服务器的网络和处理能力影响；CloudDrive2 应用通过本机的同账号网盘播放时，不占用媒体服务器的转发带宽。需要转码才能播放的格式，请换用支持它的播放器，例如 Infuse、SenPlayer 或 CloudDrive2 应用。

浏览器中有的影片不能播放，或播放不流畅

在浏览器默认设置下，请用 HTTPS 或本机 localhost 地址打开网页管理界面，以便使用 WebCodecs 硬件解码；否则，部分 4K HEVC 视频可能因软件解码而跳帧（Safari 中多数视频用 HTTP 地址也可以）。在家庭网络中，也可以设置 Chrome 和 Edge，将指定的可信 HTTP 局域网地址当作安全来源，见设置方法。DVD 和 VC-1 等格式浏览器无法播放，请点「复制链接」用 VLC、IINA、PotPlayer 或 Infuse 播放，或点「下载」，也可以用 CloudDrive2 App 播放。各浏览器的要求见网页播放器。

已经有 Emby 或 Jellyfin 服务器了

媒体文件在网盘中时，可以在「媒体库」中点「从 Emby 或 Jellyfin 导入…」，直接使用那台服务器整理好的信息、图片和观看记录，不需要重新扫描。

MoviePilot 能连接媒体服务器吗

可以。在「用户和设备 → Emby 兼容接口」中打开接口，为 MoviePilot 新建一个密钥，在 MoviePilot 中把服务器类型选为 Emby，填入页面上列出的服务器地址和密钥。见 Emby 兼容接口。

服务器关机时会怎样

连接服务器的应用显示之前读取的内容，每 30 秒重试一次，服务器开机后自动重新连接。播放器和浏览器在服务器关机时无法使用。也可以随时在应用的「设置 → 媒体库 → 同步 → 连接媒体服务器」中改回「这台设备」，由设备自己整理媒体库。

家里的孩子能看到所有内容吗

为孩子添加一个用户，只选择适合的媒体库，设置最高分级和代码，再把孩子的设备设为这个用户，或设为「每次询问」。见用户。
