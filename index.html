核心

同一套核心，装进每一台设备

CloudDrive2 的核心统一管理你所有的云盘账户，负责跨云复制、加密、备份，并对外提供 WebDAV。它既是装在电脑、NAS 或 Docker 上的后台服务，也完整内置在每个平台的应用里—— 手机、电视、头显都不需要另外架一台服务器。以下每一项都可以点开细读。

  • 云盘本地挂载

    把多个云盘挂成本地驱动器，像本地硬盘一样使用。目前唯一支持完整文件系统语义的云盘挂载： POSIX 权限、属主与扩展属性，Windows 安全描述符与 ACL，以及不必先下载整个文件的随机写。

  • 统一的多云盘管理

    在一个界面里管理全部云盘账户：整理文件、同步文件夹、跨服务商搜索。阿里云盘、百度网盘、115、天翼云盘、123云盘、OneDrive、Google Drive、迅雷云盘、WebDAV 与本地文件夹都在其中。

  • 一次登录，到处使用

    云盘账户登录一次即可在任何设备上使用。账户信息以你的密码加密，服务器只保存密码哈希，无法解密。

  • WebDAV 服务

    CloudDrive2 本身就是一台 WebDAV 服务器，可以把聚合后的云盘提供给任何 WebDAV 客户端。

  • 用 API 令牌接出去

    建一个 API 令牌，任何实现了 CloudDrive API 的客户端都能接进来——另一台 CloudDrive2，或者第三方软件。比 WebDAV 传得多：缩略图与预览、云端搜索、离线下载、秒传、容量信息和直链都在，而且逐项授权、可设有效期。

影音

云盘里的电影，就在云盘里看

CloudDrive2 App 里的播放器直接从云端读取，不必先把几十 GB 的原盘拖回本地。解码、菜单、音轨、字幕，一样不少。

Emby / Jellyfin 客户端，直连串流

登录你的 Emby 或 Jellyfin 服务器，浏览媒体库、续播、看元数据。如果服务器的媒体目录本来就在 CloudDrive 上，播放器会绕过服务器转码，直接从云端拉流——服务器不再为每一个字节做中转。

拉流之后，文件是由 CloudDrive2 App 自己的播放器打开的，所以能放什么由播放器说了算，跟服务器支不支持无关：蓝光原盘 ISO 连着 HDMV 光碟菜单、真·杜比视界 Profile 7、DSD 与 SACD ISO——这些 Emby 和 Jellyfin 本身并不支持的东西，在媒体库里点开照样能放，观看记录也照常同步回服务器。

服务器那一侧还可以装一个伴侣插件：媒体库实时更新（不必开实时监控）、按播放行为预热网盘读取，路径映射也不用再手写。

  • Direct Stream
  • 绕过服务器转码
  • 原盘 ISO 与光碟菜单
  • 服务器伴侣插件

真·杜比视界与 HDR10+

硬件加速解码 HEVC、AV1 与 H.264，支持杜比视界 Profile 5 / 7 / 8 与 HDR10、HDR10+、HLG。 Profile 7 的蓝光内容以杜比视界播放，而不是降级成 HDR10。

Profile 7 的碟片带两层画面，CloudDrive2 两层都会读；但双层输出需要设备本身支持，在大多数设备上会以单层杜比视界呈现——依然是杜比视界，而不是退回 HDR10。

  • DV P5 / 7 / 8
  • HDR10+ · HLG
  • HEVC · AV1

蓝光原盘 ISO，连光碟菜单一起

直接打开云盘里的蓝光 ISO 和 DVD ISO，进入原生的光碟菜单：选章节、选音轨、选字幕、彩色快捷键，全部可用。镜像不完整时自动跳过菜单直接播放正片。

HDMV 菜单在所有平台都支持。BD-J（Java）菜单需要 Android、Meta Quest、Windows，或 macOS 官网下载版；iPhone、iPad、Apple TV、Vision Pro 与 Mac App Store 版遇到 BD-J 光碟会直接播放正片。

  • HDMV 菜单
  • BD-J 菜单
  • DVD ISO
  • TrueHD · DTS-HD MA

几 GB 的 PDF，几秒钟打开

流式 PDF 阅读器不把整本书拖下来，只读文件里当前这几页所需的那一段。右边这本 3.31 GB、5892 页的大部头，从云端点开只要几秒；直接把进度条拖到第 4038 页，也是当场就出来——本地不留完整副本，也不占硬盘。

翻页、缩放、跳转目录都是按需取数据。页面缩略图、大纲导航、书签，以及记住你读到哪一页，一应俱全。

发烧级音频：DSD、SACD、比特完美

直接播放云端的 DSD 与 SACD ISO，经 DoP 输出到你的 USB 解码器，最高 DSD1024。应用会读出解码器自己声明的能力，你看到的采样率、位深和 DSD 档位都是它真实支持的。

  • DSD64 → DSD1024
  • DoP 1.1
  • SACD ISO
  • 杜比全景声

原生 DSD 直推需要 Android、macOS 官网下载版，或装了解码器 ASIO 驱动的 Windows；其余平台经 DoP 输出，同样比特完美。

DSD64 到 DSD1024 都支持。DoP 与原生 DSD 实际能走到哪一档，取决于所连解码器的能力——应用按解码器自己声明的规格输出，它接不了的档位会转成 PCM。

开放接口

我们自己的应用，也只是这套 API 的客户端

核心服务对外提供一整套 gRPC API，能力完整——不是挑几个只读接口开放出来的那种。CloudDrive2 的每一个平台应用，以及浏览器里的管理界面，全都完全建立在这套 API 之上：我们没有留一条自己才能走的后门。

这也意味着，第三方开发者能做的事和我们一样多。这套接口对所有开发者开放。

  • 覆盖到每一个角落

    文件操作、挂载点管理、传输任务、云盘账号、备份、WebDAV 服务、API 令牌、两步验证、会话管理，两百多个 RPC 方法，全部可用。文件系统变化通过服务端流式推送实时送达。

  • 拿到 proto 就能开工

    gRPC 走 HTTP/2，浏览器端走 gRPC-Web。下载 proto 文件，用你惯用的语言生成客户端即可——开发指南里给了 C#、Java、Go 与 Python 的完整步骤。

  • 权限自己说了算

    用 API 令牌授权，权限范围可按需勾选，还能设置有效期。给第三方程序开一个只读令牌，和给它完整权限，是两件不同的事。

curl https://www.clouddrive2.com/api/clouddrive.proto -o clouddrive.proto

这不是纸上承诺：本站提供的 Emby / Jellyfin 伴侣插件就是通过这套接口和 CloudDrive2 通信的，和任何第三方程序走的是同一条路。
