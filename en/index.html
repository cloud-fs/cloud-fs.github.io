The core

The same core, on every device

The CloudDrive2 core manages every cloud account you have and handles cross-cloud copying, encryption, backup and WebDAV. It is the background service you install on a computer, NAS or Docker host, and it is built into every platform app in full — phones, TVs and headsets need no server of their own. Each item below opens the full explanation.

  • Mount clouds as local disks

    Mount any number of clouds as local drives and use them like an internal disk. The only cloud mount with full file-system semantics: POSIX permissions, ownership and extended attributes, Windows security descriptors and ACLs, and random writes that never download the whole file first.

  • One place for every cloud

    Organise files, sync folders and search across providers from a single interface — Aliyun Drive, Baidu, 115, Tianyi, 123 Pan, OneDrive, Google Drive, Xunlei, WebDAV and local folders.

  • Sign in once, use anywhere

    Sign in to your cloud accounts once and reach them from any device. Account details are encrypted with your password, and the server only ever stores a hash of it.

  • Built-in WebDAV server

    CloudDrive2 is itself a WebDAV server, so any WebDAV client can reach your combined cloud storage.

  • PRO

    Fast cross-cloud copying

    Move files between clouds directly, without downloading them first. Saves your time and your bandwidth.

  • PRO

    File change notifications

    Get notified the moment a cloud file changes, so filesystem-watching tools keep working as they should.

  • PRO

    Encrypted filesystem

    Create encrypted folders in any cloud or local folder. Filenames use AES, contents use chacha20-poly1305, and the password never leaves your machine. Unlocked, it behaves like any other folder.

  • PRO

    Per-application permissions

    Define and manage file access per program, so you control exactly which app can read or write what.

  • Fair to the cloud providers

    CloudDrive2 keeps your experience smooth while using as little of the provider's capacity as it can.

  • PRO

    Multi-cloud backup

    Back any local disk or cloud up to several destinations at once, with automatic change detection, incremental runs and unlimited version history for overwrites and deletions.

  • Runs on nearly anything

    Windows, Linux and macOS computers. Synology, QNAP, Unraid and fnOS NAS boxes. Android phones and TV boxes. Even OpenWRT routers.

Media

Watch what's in the cloud, from the cloud

The CloudDrive2 player reads straight from cloud storage, so a 60 GB disc image never has to come down to your device first. Decoding, menus, audio tracks and subtitles all come with it.

Emby & Jellyfin client with Direct Stream

Sign in to your Emby or Jellyfin server to browse libraries, resume playback and read metadata. When the server's media folder lives on CloudDrive anyway, the player skips the server's transcoder and pulls from the cloud directly — your server stops relaying every byte.

  • Direct Stream
  • No server transcode
See it on iPhone and iPad

True Dolby Vision and HDR10+

Hardware-accelerated HEVC, AV1 and H.264 decoding, with Dolby Vision Profiles 5, 7 and 8 alongside HDR10, HDR10+ and HLG. Profile 7 Blu-ray content plays as genuine dual-layer Dolby Vision rather than falling back to HDR10.

  • DV P5 / 7 / 8
  • HDR10+ · HLG
  • HEVC · AV1
See it on the Mac

Blu-ray ISOs, disc menus included

Open a Blu-ray or DVD ISO straight from the cloud and get the real disc menu: chapter selection, audio tracks, subtitle tracks, coloured shortcut keys. If the image is incomplete, playback skips the menu and starts the main feature.

HDMV menus work on every platform. BD-J (Java) menus need Android, Meta Quest, Windows or the macOS build downloaded from this site; on iPhone, iPad, Apple TV, Vision Pro and the Mac App Store build a BD-J disc plays the main feature directly.

  • HDMV menus
  • BD-J menus
  • DVD ISO
  • TrueHD · DTS-HD MA
See disc menus on Android

AI subtitle translation, on your device

Transcribe a film that has no subtitles and translate it into your language, or translate an existing foreign-language track in full. Both steps run locally — no audio is sent to any server. Generated subtitles are saved next to the video, so another device can reuse them.

  • On-device transcription
  • Whole-track translation
  • Saved as SRT
See the subtitle settings

A multi-gigabyte PDF, open in seconds

The streaming PDF reader never pulls the whole book down, fetching only the byte range the pages you are looking at actually need. The 3.31 GB, 5892-page volume beside this opens from the cloud in seconds, and dragging the scrubber to page 4038 renders on the spot — with no complete copy left on your disk.

Turning pages, zooming and jumping through the outline all fetch on demand. Page thumbnails, outline navigation, bookmarks and reading-position memory are all there.

  • Fetches pages on demand
  • No full download
  • Bookmarks and position
See it on Windows

Audiophile audio: DSD, SACD, bit-perfect

Play DSD files and SACD ISOs straight from the cloud, sent over DoP to your USB DAC at up to DSD1024. The app reads the capabilities the DAC itself reports, so the sample rates, bit depths and DSD tiers you see are the ones it genuinely supports.

  • DSD64 → DSD1024
  • DoP 1.1
  • SACD ISO
  • Dolby Atmos

Native DSD straight to the DAC needs Android, the macOS build downloaded from this site, or Windows with your DAC's ASIO driver installed. Everywhere else it goes over DoP, which is equally bit-perfect.

See the audio settings on Android

180°/360° VR video, Apple Spatial video and MVC 3D Blu-ray, streamed from the cloud. On Vision Pro subtitles follow the depth of the picture automatically; on Quest you pick a cinema environment and set the screen's distance and curvature.

  • 180° / 360°

A ¥299 lifetime tier, and a commitment

Since CloudDrive launched we have received many letters from users with visual impairments — not only kind words, but specific, practical suggestions about accessible interfaces. We commit to taking accessibility fully into account, and continuing to improve it, in the interface work ahead.

Those letters taught us how much effort it takes to operate several separate cloud-drive clients one by one. Mounting every cloud as a single system drive removes that layer of work entirely — which is exactly what CloudDrive does.

So while the lifetime membership has returned to its regular ¥499, we keep a ¥299 lifetime tier available. Email us the name and certificate number on your visual-disability certificate, and we will review it and send a discount code straight away. Redeem it on a direct in-app purchase with your CloudDrive account — store rules mean discount codes cannot be applied through the App Store, Google Play or the Meta store.
