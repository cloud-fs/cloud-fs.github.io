影音

影院级播放，直接从云端

不用先把几十 GB 的原盘下载到本地，也不用架一台 NAS。播放器直接从云端读取， 解码、菜单、音轨、字幕一样不少。

影院级播放与蓝光原盘

H.264、H.265/HEVC、AV1 硬件加速解码，支持 HDR10、HDR10+ 输出信号与杜比视界—— 包括 Profile 7 蓝光内容的真·杜比视界播放。帧率匹配消除画面抖动， 进度条带缩略图预览，看到一半退出后可以断点续播。

蓝光 ISO 直接从云存储播放，并进入原生的原盘菜单：场景选择、遥控器上的彩色快捷键、 菜单内音轨与字幕设置，以及 2D+3D 合装碟。

原盘菜单适用于 HDMV 光盘。BD-J（Java）光盘在 Apple 平台会直接播放正片；如需 BD-J 菜单，请看 Android 版。

  • 杜比视界 P5 / 7 / 8
  • HDR10+ · 帧率匹配
  • HDMV 原盘菜单
  • 2D + 3D 合装碟

字幕体验拉满

SRT、ASS/SSA、VTT 与 PGS 图形字幕，支持样式调节、独立延迟和 HDR 亮度调节。

AI 字幕翻译在 Apple TV 上通过你自己的 API 生成。更省事的做法是： 先在 iPhone 或 Mac 上生成字幕——它会保存在云端视频旁边—— Apple TV 打开同一个文件时直接复用，不必在电视上重新跑一遍。

tvOS 没有 Apple 的端侧翻译模型，因此电视上的 AI 字幕只能接入你自己的 API；端侧模型请在 iPhone、iPad 或 Mac 上使用。

  • 接入自有 API
  • 跨设备复用字幕
  • PGS 图形字幕
  • HDR 字幕亮度

无损音乐、杜比全景声与多声道环绕

Apple TV 上的完整音频播放器：FLAC、WAV、ALAC、APE，DSD 最高支持 DSD1024， 还支持 SACD ISO 播放。专辑封面、无缝播放和后台播放——浏览文件时音乐不间断， 遥控器上可用「正在播放」控制。

杜比全景声（杜比数字+）通过 HDMI 以比特流直通输出到功放或回音壁。TrueHD、 DTS-HD Master Audio 和 DTS 音轨完整解码，经 HDMI 以 5.1 或 7.1 多声道输出—— 绝不强制下混成立体声。多声道 DSD 同样如此：5.1 声道的 SACD ISO、.dsf 与 .dff 通过功放以真正的环绕声播放。完整环绕声场始终保留，所以 AirPods Pro / Max 可享受带头部追踪的空间音频， 立体声设备则采用标准 ITU-R BS.775 下混。

  • DSD64 → DSD1024
  • SACD ISO
  • 杜比全景声比特流
  • 后台播放

日常会用到的其余部分

  • 云端影音中心

    Google Drive、OneDrive、阿里云盘、百度网盘、115、S3、WebDAV 等等，全部连到一处。用为 Siri Remote 优化的电视界面在沙发上浏览所有云盘，网格与列表视图、缩略图预览，数千文件的文件夹也能快速导航。

  • Emby / Jellyfin 客户端

    连接你自己的 Emby 或 Jellyfin 服务器，海报墙、演职人员、继续观看一应俱全。本机 CloudDrive 能访问同一文件时，「直连串流」直接从云端拉流，绕过服务器转码，观看记录仍与服务器同步。

  • 影库元数据

    自动读取本地 .nfo 文件与海报图片（Plex / Jellyfin / Emby 命名规范），打造丰富且私有的影库——不联网抓取。

  • PDF 与文档

    全屏查看云端 PDF，翻页与缩放都为遥控器做了适配。

  • 共享与安全

    使用 CloudDrive 账号登录，两步验证与活动会话监控守护你的数据。内置 WebDAV 服务器可把云端文件共享给同一网络下的其他设备，API 令牌可授予限定权限和有效期的访问。

  • 还有这些

    网格与列表视图随时切换、缩略图进度预览与断点续播、遥控器上的「正在播放」控制、深色与浅色主题、中英文界面。
