云盘

多云盘聚合

所有网盘，一个应用

115、阿里云盘、百度网盘、123云盘、迅雷云盘、天翼云盘、光鸭云盘、 S3 与兼容对象存储、Google Drive、OneDrive、WebDAV、SMB、FTP/SFTP、远程 CloudDrive 服务端、本机文件夹等等，全部连到一处。跨云盘统一的列表与网格视图、排序、搜索、多选；上传（含文件夹递归上传）、下载、复制、移动、重命名、删除与新建文件夹，都是跨云盘操作，而不只是在单个云盘内。

添加账号时支持扫码与 OAuth 授权登录。界面上写得很清楚：「我们只保存密码哈希，无法解密您的凭据」。

把云盘挂载为本机目录属于「挂载管理」，在手机上需要 Root 权限；未获取 Root 时，应用会直接给出提示。日常浏览、播放与传输都不需要 Root。

  • 跨云搜索
  • 扫码 / OAuth 登录
  • S3 · WebDAV · SMB

影音

发烧级播放器，直连云端

基于 FFmpeg 与 Media3 / ExoPlayer，几十 GB 的原盘不用先下载，也不用挂载，直接从云端串流。

蓝光原盘光碟菜单，HDMV 与 BD-J 都支持

直接播放云端的蓝光 ISO 镜像或 BDMV 文件夹，并进入真正的光碟菜单。 HDMV 与 Java（BD-J）两种菜单都能用——BD-J 靠应用内置的 OpenJDK 运行时实现，这是 Android 版独有的一点：Apple 平台只支持 HDMV。

菜单导航、选段、Play All 都在；可以在菜单会话内直接播放正片，所选音轨与字幕带入正片。彩色快捷键、会话内 PGS 字幕渲染、外挂 .ass / .srt 字幕，以及合并的「继续观看 / 光碟菜单」选择器一应俱全。截断或不完整的镜像会自动跳过菜单、直接播放完整正片。MVC 3D 立体蓝光同样支持。

  • BD-J（内置 OpenJDK）
  • HDMV 菜单
  • ISO 与 BDMV 文件夹
  • MVC 3D 蓝光

HDR、杜比视界与解码

HDR10、HDR10+ 与 Dolby Vision（含 P5 / P7 / P8）。TS / M2TS 重封装的片源也能正确识别 HDR 与帧率，不会因为换了封装就丢掉动态元数据。4K、8K 与 AV1 都能播；硬件解码器啃不动的 H.264 High Profile 会自动回退到 FFmpeg 解码。

杜比视界输出取决于设备：需要电视或盒子本身支持杜比视界输出，不具备这个能力的机器上会以 HDR10 等格式播放。Profile 7 的碟片带两层画面，CloudDrive2 两层都读，并把增强层合成进最终画面，完整增强层（FEL）的片源同样如此。已知问题：Android TV 设备上 FEL 合成暂不生效，正在排查，会在后续版本修复；手机与平板不受影响。

  • HDR10 · HDR10+
  • 杜比视界 P5 / 7 / 8
  • 8K · AV1
  • FFmpeg 回退解码

AI 实时字幕翻译

边看边译。优先翻译已有字幕轨（包括通过 OCR 识别的 PGS 图形字幕），没有字幕轨时才使用语音识别。可以完全在设备端跑——whisper.cpp 负责转写、ML Kit 负责翻译，音频不出手机—— 也可以接远程 API：OpenAI、Groq、Qwen，或你自建的 Speaches / MTranServer。

生成的字幕可以存回云盘，换台设备直接复用。

  • 端侧 whisper.cpp
  • 端侧 ML Kit 翻译
  • PGS OCR
  • 字幕存回云盘

USB 解码器与 DSD / SACD

插上 USB DAC，应用会自动识别设备能力：采样率范围、位深，以及 DoP 支持到哪一档。内置的 USB 音频驱动（USBFS）与 DST 解码绕过 Android 混音器，直接输出比特完美的信号。

DSF、DFF 与 SACD ISO 都能直接从云端播放，支持 DoP 输出、USB DAC 原生 DSD 直推与多声道 DSD。 HDMI 上则有 Dolby Atmos / TrueHD 直通与多声道输出。

DSD64 到 DSD1024 都支持。DoP 与原生 DSD 实际能走到哪一档，取决于所连解码器的能力——应用按解码器自己声明的规格输出，它接不了的档位会转成 PCM。

  • DSD64 → DSD1024
  • USBFS 比特完美
  • SACD ISO · DST
  • Atmos / TrueHD 直通

音乐播放器

Now Playing 界面、媒体通知与锁屏控制、cue 表支持，以及多声道 DSD 播放。整张 SACD ISO 或一堆 DSF 放在云盘上，点开就听，不必先同步到本地。

  • 原生 DSD
  • cue 表
  • 锁屏控制

Android TV

电视与电视盒子

同一个应用，装到 Android TV 或电视盒子上就换成以焦点为核心的电视界面，完整适配 D-pad 遥控器。

遥控器优先的电视界面

面包屑、焦点框与返回键都按遥控器的操作习惯做过适配，横屏仪表盘一屏放下容量卡片和常用入口，不用在电视上戳一个为触摸设计的界面。

  • D-pad 导航
  • 横屏仪表盘

Emby / Jellyfin 客户端与直连串流

在应用内浏览并播放 Emby 或 Jellyfin 媒体库，按类型、评分、标签筛选。配置好路径映射之后，「直连串流」会经本机 CloudDrive 直接从云端拉流，避免每字节都经过媒体服务器——服务器转不动的格式也能原画质播放。AI 生成的字幕还能回传媒体服务器。

手机、平板和电视上都能用，不是电视端专属。

服务器那一侧还可以装 Emby / Jellyfin 伴侣插件：媒体库实时更新、按播放行为预热，路径映射也会自动配好。

  • Direct Stream
  • 路径映射
  • 字幕回传服务器

HDMI 直通与显示模式匹配

电视端有独立的音频引擎，可以切换音轨、把 SACD 多声道经 HDMI 输出， Dolby Atmos 与 TrueHD 直通到功放。在 Amlogic 盒子上还支持 HDMI HDR 直通，以及按片源自动匹配帧率与显示模式——24p 的电影就按 24p 输出，不再多一层插帧。

  • HDMI 音频直通
  • 自动匹配帧率
  • HDR 直通（Amlogic）

大屏上的 AI 字幕

字幕翻译在电视上同样可用，转写可以完全跑在盒子本地（whisper），看外语片时不用先去找字幕文件。字幕样式、字号与位置、HDR 字幕亮度都能在电视端调。

  • 端侧 whisper 转写
  • HDR 字幕亮度

双栏浏览与文件检查器

电视上的文件浏览采用左右双栏：左边目录，右边检查器，选中哪个文件就能看清它的编码、大小与轨道信息，遥控器点几下就能确认这个片源到底是什么。

  • 双栏浏览
  • 检查器面板

更多

日常会用到的其余部分

  • 图库与图片查看

    全分辨率 1:1 查看、EXIF 方向自动校正、幻灯片播放与亮度记忆。照片放在云盘上，翻起来跟本地一样顺。

  • 流式 PDF 阅读器

    几个 GB 的大部头 PDF，直接从云端点开就能读，通常几秒钟就能看见第一页。阅读器只读当前这几页所需的那一段字节，不必先把整本下载下来，本地也不留完整副本。

  • 备份与传输

    多目标自动备份任务，支持定时扫描与过滤规则，可自动创建目标子文件夹。跨云盘复制与移动，传输管理器支持暂停、恢复、重试、限速与并发控制。

  • 字幕与画面调节

    外挂 ASS / SRT / VTT、内嵌文本轨，以及用 libass 渲染的 PGS 图形字幕。字幕样式、字号与位置、HDR 字幕亮度，音频与字幕的延迟可以分别调。

  • 应用内更新

    直接安装 APK 的用户也不会漏掉新版本：应用会自动检查更新并提示。从 Google Play 安装则由商店负责更新。

  • 系统文件选择器（SAF）

    接入 Android 的存储访问框架，其他应用可以在系统的文件选择器里直接浏览和打开你的云端文件，和打开本机文件一样。

  • 自带 WebDAV 服务器

    这台 Android 手机、平板或电视盒子本身就是一台 WebDAV 服务器：所有已连接的云盘以标准协议对外提供，同一网络下的第三方应用——播放器、文件管理器、备份工具——直接连上来就能读到云端内容，不必再各自登录一遍云盘。

  • 还有这些

    深色与浅色主题、中英文界面，以及与 CloudDrive 服务端、网页端、Apple 与 Meta Quest 版本对齐的功能集。

安装说明

通用版本，覆盖 arm64-v8a 与 armeabi-v7a，需要 Android 7.0 或更高版本。同一个安装包同时适配手机、平板与 Android TV / 电视盒子。

关于 App Pro

浏览云盘、管理文件、基础播放都不需要额外购买。 HDR 与杜比视界、DSD、ISO 光盘播放（蓝光 / DVD / SACD）、AI 字幕翻译，以及媒体客户端（Emby / Jellyfin）这几项进阶播放功能，需要一次性的 App Pro 内购。

App Pro 绑定的是你的 CloudDrive 账号，不是设备也不是商店。买过一次，在任何平台上登录同一账号都已解锁——Android、Apple 设备与 Meta Quest 一视同仁。详见会员与价格。

关于这些功能

本页写的是应用当前的功能。CloudDrive2 仍在持续开发，云服务商与各平台的限制也在变，所以功能可能调整，也可能在不另行通知的情况下移除。

欢迎提功能需求、报 bug——下一个版本做什么，很大程度上就是这么定的。最好提到 GitHub issues 上，有记录也追得到；也可以写信到 waytechcloudfs@gmail.com，或者加入 Telegram 群。
