云盘

统一云盘管理

一站式连接所有云账号

Google Drive、OneDrive、阿里云盘、百度网盘、115、S3、WebDAV 等等，全部连到一处。在一个清爽的界面里跨云浏览、搜索、复制、移动、重命名和整理文件。

  • 跨云搜索
  • S3 · WebDAV · SFTP

iPad 上的分栏视图与检查器

iPad 版提供 Finder 风格的分栏视图和文件检查器面板，配合外接键盘，再大的文件库也能一层层点进去、一眼看清属性。列表、网格、画廊、分栏四种视图随时切换。

  • 分栏视图
  • 检查器面板
  • 画廊缩略图

深度集成「文件」应用

完整的 File Provider 扩展，让你在 iOS / iPadOS 的「文件」应用里，以及任何调用文档选择器的应用里，直接访问云端文件。 CloudDrive2 也可以通过 clouddrive:// URL 方案，作为其他应用的外部播放器。

  • File Provider
  • clouddrive:// 外部播放器

影音

影院级播放，直接从云端

不用先把几十 GB 的原盘拖回手机。播放器直接从云端读取，解码、菜单、音轨、字幕一样不少。

Emby / Jellyfin 客户端，直连串流

连接你自己的 Emby 或 Jellyfin 服务器，海报墙、演职人员、继续观看一应俱全。当本机 CloudDrive 能访问同一个文件时，「直连串流」会直接从云端拉流播放，绕过服务器转码——服务器转不动的格式也能原画质播放，观看记录仍与服务器同步。

服务器那一侧还可以装 Emby / Jellyfin 伴侣插件：媒体库实时更新、按播放行为预热，路径映射也会自动配好。

  • Direct Stream
  • 观看记录同步

强大的媒体播放器

硬件加速解码 H.264、H.265/HEVC、AV1，支持 HDR10、HDR10+ 与杜比视界—— 包括 Profile 7 蓝光内容的杜比视界播放。画中画、音频与字幕独立延迟调节、字幕样式与 HDR 字幕亮度调节，都在播放器里。

Profile 7 的碟片带两层画面，CloudDrive2 两层都会读；但双层输出需要设备本身支持，在大多数设备上会以单层杜比视界呈现——依然是杜比视界，而不是退回 HDR10。

  • 杜比视界 P5 / 7 / 8
  • HDR10+ · HLG
  • 画中画

蓝光 ISO，原盘菜单直接用

直接从云存储播放蓝光 ISO 镜像，并进入原生的原盘菜单：场景选择、彩色快捷键、菜单内音轨与字幕设置，甚至 2D+3D 合装碟。

原盘菜单适用于 HDMV 光盘。BD-J（Java）光盘在 iPhone 与 iPad 上会直接播放正片；需要 BD-J 菜单，可以用 Windows 版、macOS 直接下载版、Android 版或 Meta Quest 版。

  • HDMV 菜单
  • 2D + 3D 合装碟
  • 场景选择

AI 字幕翻译

为任何视频生成翻译字幕：优先翻译已有字幕轨（包括通过端侧 OCR 识别的 PGS 图形字幕），没有字幕时自动回退到语音识别。可以使用 Apple 的端侧翻译模型——免费，而且音频不出设备—— 也可以接入你自己的 API。生成的字幕保存在视频旁边，换台设备就能直接复用。

  • Apple 端侧模型
  • PGS OCR
  • 字幕存档复用

多声道、杜比全景声与发烧级 DSD

杜比全景声（杜比数字+）可经 HDMI 比特流直通到功放。TrueHD、DTS-HD Master Audio 与 DTS 完整解码，以 5.1 或 7.1 输出到多声道 USB 解码器、HDMI 转接器和 AirPlay 2，绝不强制下混成立体声； AirPods Pro / Max 则启用带头部追踪的空间音频。

DSD 文件（.dsf、.dff）和 SACD ISO 直接从云端播放，包括真正的 5.1 多声道 DSD，经 DoP 比特完美送到兼容解码器。锁屏之后音乐照常继续。

DSD64 到 DSD1024 都支持。DoP 与原生 DSD 实际能走到哪一档，取决于所连解码器的能力——应用按解码器自己声明的规格输出，它接不了的档位会转成 PCM。

  • DSD64 → DSD1024
  • SACD ISO
  • TrueHD · DTS-HD MA
  • 后台播放

几 GB 的 PDF，几秒钟打开

流式 PDF 阅读器不把整本书拖下来。它只读当前这几页所需的那一段字节，所以一本几个 GB 的画册，从云端点开到看见第一页通常只要几秒—— 不必等待完整下载，本地也不留完整副本。

翻页、缩放、跳转目录都是按需取数据。页面缩略图、书签，以及记住你读到哪一页，一应俱全。

  • 按需读取页面
  • 无需完整下载
  • 页面缩略图
  • 书签与阅读位置

日常会用到的其余部分

  • 影库元数据

    自动读取本地 .nfo 文件与海报、剧照、Logo（Plex / Jellyfin / Emby 命名规范）。不联网抓取，影库完全私有。

  • 跨云传输

    在不同服务商之间复制或移动文件。传输管理器支持暂停、恢复、重试、限速与并发控制，也支持整个文件夹递归上传。

  • 备份与同步

    创建带定时计划的自动备份任务，照片图库也可以整体备份上云。

  • 安全

    两步验证、加密文件夹与活动会话监控。API 令牌可授予限定权限和有效期的访问。

  • 自带 WebDAV 服务器

    这台 iPhone 或 iPad本身就是一台 WebDAV 服务器：所有已连接的云盘以标准协议对外提供，同一网络下的第三方应用——播放器、文件管理器、备份工具——直接连上来就能读到云端内容，不必再各自登录一遍云盘。

  • 还有这些

    可配置淘汰策略的磁盘缓存与离线访问、四种视图模式、用 Infuse / VLC / nPlayer 等第三方播放器打开、后台音频播放、深色与浅色主题、中英文界面。

关于 App Pro

浏览云盘、管理文件、传输与备份、基础播放都不需要额外购买。 HDR 与杜比视界、DSD、ISO 光盘播放（蓝光 / DVD / SACD）、AI 字幕翻译，以及媒体客户端（Emby / Jellyfin）这几项进阶播放功能，需要一次性的 App Pro 内购。App Pro 绑定的是你的 CloudDrive 账号，不是设备也不是商店。买过一次，在任何平台上登录同一账号都已解锁——iPhone、iPad、Mac、Apple TV、Vision Pro、Android 与 Meta Quest 一视同仁。详见会员与价格。

关于这些功能

本页写的是应用当前的功能。CloudDrive2 仍在持续开发，云服务商与各平台的限制也在变，所以功能可能调整，也可能在不另行通知的情况下移除。
