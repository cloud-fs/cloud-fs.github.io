云盘

统一云盘管理

一站式连接所有云账号

Google Drive、OneDrive、S3、阿里云盘、百度网盘、115、迅雷、WebDAV、SFTP、FTP、SMB 等等，全部连到一处。以专为 Mac 设计的清爽界面跨云浏览、搜索、复制、移动、重命名和整理文件： Finder 风格分栏视图、可排序的列表表头与内联筛选、带内联预览的文件检查器， 以及任意两个云之间的拖放。

直接下载版还能把云盘挂载成 Mac 上的一块磁盘，在 Finder 里像本地硬盘一样浏览， 第三方应用和命令行也能直接访问。

本地挂载依赖 macFUSE，只在直接下载版中提供；App Store 版运行在完整沙盒中，不含这项功能。两版差异见下方对照表。

  • 跨云搜索
  • 分栏视图与检查器
  • 跨云拖放

影音

影院级播放，直接从云端

不用先把几十 GB 的原盘拖回硬盘。播放器直接从云端读取，解码、菜单、音轨、字幕一样不少。

内置播放器与蓝光原盘

VideoToolbox 硬件加速解码 H.264、H.265/HEVC、AV1，支持 HDR10、HDR10+ 与杜比视界—— 包括 Profile 7 蓝光内容的真·杜比视界播放。字幕支持 SRT、ASS/SSA、VTT 与 PGS， 可独立调节延迟、样式与 HDR 亮度；影片信息自动读取本地 .nfo 元数据与海报、Logo 图片。

蓝光 ISO 直接从云存储串流，并进入原生的原盘菜单：场景选择、彩色快捷键、 菜单内音轨与字幕设置、2D+3D 合装碟与章节导航。

原盘菜单适用于 HDMV 光盘。BD-J（Java）光盘在 Apple 平台会直接播放正片；如需 BD-J 菜单，请看 Android 版。

  • 杜比视界 P5 / 7 / 8
  • HDR10+ · HLG
  • HDMV 原盘菜单
  • 2D + 3D 合装碟

AI 字幕翻译

为任何视频生成翻译字幕：优先翻译已有的字幕轨（包括通过端侧 OCR 识别的 PGS 图形字幕）， 没有字幕时自动回退到语音识别。可以使用 Apple 的端侧翻译模型——免费，而且音频不出设备—— 也可以接入你自己的 API。生成的字幕保存在视频旁边，换台设备就能直接复用， 整个文件夹也可以在后台批量生成。

  • Apple 端侧模型
  • PGS OCR
  • 整文件夹批量
  • 字幕存档复用

多声道与杜比全景声

杜比全景声（杜比数字+）可通过 HDMI 以比特流直通输出到功放。TrueHD、DTS-HD Master Audio 和 DTS 音轨完整解码，以 5.1 或 7.1 多声道经 HDMI 或多声道 USB 解码器输出——绝不强制下混成立体声。 多声道 DSD 同样如此：5.1 声道的 SACD ISO、.dsf 与 .dff 以真正的环绕声播放。

立体声设备则采用标准 ITU-R BS.775 下混，AirPods Pro / Max 启用带头部追踪的空间音频。

  • 杜比全景声比特流
  • TrueHD · DTS-HD MA
  • 5.1 · 7.1 不下混
  • 空间音频

发烧级音频

DSD 播放最高支持 DSD1024，也支持 SACD ISO、FLAC、WAV、ALAC 等 25 种以上格式。 DoP 输出和按设备固定的音频输出，把比特完美的信号送进你的 USB 解码器。 无缝播放、重建的常驻音频播放器，以及保持音调的变速播放。

USB 原生 DSD（Native DSD）需要直接下载版；App Store 版以 DoP 输出 DSD，同样是比特完美。

  • DSD64 → DSD1024
  • SACD ISO
  • DoP 比特完美
  • 无缝播放

几 GB 的 PDF，几秒钟打开

流式 PDF 阅读器不把整本书拖下来。它只读当前这几页所需的那一段字节， 所以一本几个 GB 的画册，从云端点开到看见第一页通常只要几秒—— 不必等待完整下载，硬盘上也不留完整副本。

阅读器在独立窗口中打开。翻页、缩放、跳转目录都是按需取数据， 页面缩略图、大纲导航、书签与阅读位置记忆一应俱全， 换一台登录同一 CloudDrive 账号的设备接着读，位置还在。

  • 按需读取页面
  • 无需完整下载
  • 大纲导航
  • 书签与阅读位置

更多

日常会用到的其余部分

  • 全键盘操控

    方向键导航文件、空格快速预览、F2 重命名、字母前缀跳转，以及完整的播放器控制——快进快退、音量、全屏、下一集、音轨与字幕循环切换、逐帧步进和媒体键。按 ⌘⇧/ 查看快捷键速查表。

  • Emby / Jellyfin 客户端

    连接你自己的 Emby 或 Jellyfin 服务器，海报墙、演职人员、继续观看一应俱全。本机 CloudDrive 能访问同一文件时，「直连串流」直接从云端拉流，绕过服务器转码，观看记录仍与服务器同步。

  • Finder 集成

    File Provider 扩展把已连接的云账号作为位置显示在 Finder 中，任何 Mac 应用都能浏览和打开云端文件。CloudDrive2 也可以通过「打开方式」和 clouddrive:// URL 方案充当视频文件的外部播放器。

  • 跨云传输与自动备份

    在任意已连接的服务商之间复制或移动文件，传输管理器支持暂停、恢复、重试、限速与并发控制，也支持整个文件夹递归上传。备份任务支持文件系统监控、全量扫描间隔与多目标冗余。

  • WebDAV 与安全

    内置 WebDAV 服务器把 Mac 变成标准协议的入口，网络上的其他应用和设备可直接访问云端文件。两步验证、加密文件夹、细粒度权限的 API 令牌与活动会话监控守护你的数据。

  • 还有这些

    可配置淘汰策略的磁盘缓存与离线访问、带缩略图预览的画廊视图、支持 RAW（CR2/NEF/ARW/RAF）的图片查看器、画中画、后台音频播放、AirPlay 2 多房间音频、深色与浅色主题、中英文界面，以及在 Apple 芯片和 Intel Mac 上均原生运行的通用二进制。
