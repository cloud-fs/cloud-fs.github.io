云盘

统一云盘管理

所有云存储，一个空间

Google Drive、OneDrive、阿里云盘、百度网盘、115、S3、WebDAV、SFTP、FTP、SMB 等等，全部连到一处。跨云浏览、搜索、复制、移动、重命名和整理文件；跨云传输可暂停与恢复，自动备份任务、文件夹递归上传和流式 PDF 阅读器也都在同一个应用里。

完整的 File Provider 扩展，让云端文件直接出现在 visionOS 的「文件」应用，以及任何调用文档选择器的应用里。窗口可以并排摆开，边整理文件边放着电影。

  • 跨云搜索
  • S3 · WebDAV · SMB
  • File Provider

影音

从平面电影到全沉浸 VR

几十 GB 的原盘不必先拖回本地。播放器直接从云端读取，解码、菜单、音轨、字幕一样不少。

在沉浸空间里可以观看 180°/360° VR 视频、Apple 空间视频（MV-HEVC）、左右与上下立体 3D、鱼眼和 EAC 立方体贴图内容，保留透视画面更舒适。头部锁定字幕跟随视线；播放 VR 视频时，字幕还会自动跟随画面的景深，眼睛不必在文字和画面之间反复对焦。平面视频没有景深可跟，字幕就停在屏幕平面上。

影院级平面播放与蓝光原盘

H.264、H.265/HEVC、AV1——包括 8K AV1 实时播放——支持 HDR10、HDR10+ 和杜比视界，包括 Profile 7 蓝光内容的杜比视界播放。屏幕想放多大就放多大，坐在哪儿都是正对着看。

Profile 7 的碟片带两层画面。CloudDrive2 两层都读，并把增强层合成进最终画面，完整增强层（FEL）的片源同样如此，放出来就是完整的双层杜比视界。这项能力随 App 1.0.15 上线，该版本正在 App Store 审核中；在此之前 Profile 7 以基础层的单层杜比视界呈现——依然是杜比视界，而不是退回 HDR10。

蓝光 ISO 直接从云端播放，并进入原生的原盘菜单：场景选择、彩色快捷键、菜单内音轨与字幕设置，甚至 2D+3D 合装碟。ISO 里的 MVC 3D 蓝光原生解码左右眼画面，跨进度跳转、章节和片段切换都保持立体 3D。

原盘菜单适用于 HDMV 光盘。BD-J（Java）光盘在 Vision Pro 上会直接播放正片；需要 BD-J 菜单，可以用 Windows 版、macOS 直接下载版、Android 版或 Meta Quest 版。

  • 8K AV1
  • 杜比视界 P5 / 7 / 8
  • HDMV 菜单
  • MVC 3D 蓝光

AI 字幕翻译

为任何视频生成翻译字幕：优先翻译已有字幕轨（包括通过端侧 OCR 识别的 PGS 图形字幕），没有字幕时才回退到语音识别。可以使用 Apple 的端侧翻译模型——免费，音频也不出设备—— 也可以接入你自己的 API。

生成的字幕保存在视频旁边，换台设备就能直接复用；在沉浸模式下同样跟随视线呈现。

  • Apple 端侧模型
  • PGS OCR
  • 字幕存档复用

多声道与发烧级音频

杜比全景声、TrueHD、DTS-HD Master Audio 和 DTS 音轨以完整 5.1 或 7.1 解码，再渲染为带头部追踪的空间音频——整个环绕声场摆在你周围，而不是下混成立体声。 Vision Pro 自带扬声器和 AirPods Pro / Max 都可以。

多声道 DSD 同样如此：5.1 声道 SACD ISO、.dsf 与 .dff 以真正的环绕声播放。此外还支持 FLAC、WAV、ALAC，DSD 播放最高支持 DSD1024，并支持 DoP 输出。

DSD64 到 DSD1024 都支持。DoP 与原生 DSD 实际能走到哪一档，取决于所连解码器的能力——应用按解码器自己声明的规格输出，它接不了的档位会转成 PCM。

  • DSD64 → DSD1024
  • 多声道 SACD ISO
  • TrueHD · DTS-HD MA
  • 头部追踪空间音频

几 GB 的 PDF，几秒钟打开

流式 PDF 阅读器不把整本书拖下来。它只读当前这几页所需的那一段字节，所以一本几个 GB 的画册，从云端点开到看见第一页通常只要几秒—— 不必等待完整下载，本地也不留完整副本。

阅读器面板就悬在你的空间里，和其他窗口并排摆着，想放多大放多大。翻页、缩放、跳转目录都是按需取数据，页面缩略图、书签与阅读位置记忆一应俱全。

  • 按需读取页面
  • 无需完整下载
  • 悬浮面板
  • 书签与阅读位置

更多

日常会用到的其余部分

  • Emby / Jellyfin 客户端

    连接你自己的 Emby 或 Jellyfin 服务器，海报墙、演职人员、继续观看一应俱全。当本机 CloudDrive 能访问同一个文件时，「直连串流」直接从云端拉流播放，服务器转不动的格式也能原画质播放，观看记录仍与服务器同步。

    服务器那一侧还可以装 Emby / Jellyfin 伴侣插件：媒体库实时更新、按播放行为预热，路径映射也会自动配好。

  • 支持的沉浸格式

    180° 与 360° VR 视频、Apple 空间视频（MV-HEVC）、左右与上下立体 3D、鱼眼、EAC 立方体贴图，以及 ISO 里的 MVC 3D 蓝光。播放时可保留透视画面，看久了也不闷。

  • 跨云传输与备份

    在不同服务商之间复制或移动文件，传输可暂停与恢复。自动备份任务按计划运行，文件夹递归上传一次搞定。

  • 安全

    两步验证、加密文件夹与活动会话监控。API 令牌可授予限定权限和有效期的访问。

  • 自带 WebDAV 服务器

    这台 Vision Pro本身就是一台 WebDAV 服务器：所有已连接的云盘以标准协议对外提供，同一网络下的第三方应用——播放器、文件管理器、备份工具——直接连上来就能读到云端内容，不必再各自登录一遍云盘。

  • 还有这些

    影库读取本地 .nfo 与海报（Plex / Jellyfin / Emby 命名规范，不联网抓取）、可配置淘汰策略的磁盘缓存、音频与字幕独立延迟调节、深色与浅色主题、中英文界面。

关于 App Pro

浏览云盘、管理文件、传输与备份、基础播放都不需要额外购买。 HDR 与杜比视界、DSD、ISO 光盘播放（蓝光 / DVD / SACD）、AI 字幕翻译、媒体客户端（Emby / Jellyfin），以及各类 VR 视频播放（VR180、360、鱼眼、EAC、3D SBS/OU 等）这几项，需要一次性的 App Pro 内购，各商店标价 USD $19.99。App Pro 绑定的是你的 CloudDrive 账号，不是设备也不是商店。买过一次，在任何平台上登录同一账号都已解锁——iPhone、iPad、Mac、Apple TV、Vision Pro、Android 与 Meta Quest 一视同仁。详见会员与价格。
