安装与运行

重要提示：安装完成后，用浏览器打开 http://<安装CloudDrive的主机IP>:19798 打开管理界面。建议采用最新版Edge、Chrome、Safari或者Firefox浏览器，不支持IE浏览器。

Windows

  1. 访问我们的官方网站下载 CloudDrive。
  2. 打开安装包，按照屏幕上的提示进行操作。
  3. 安装完成后，您可以在桌面找到CloudDrive2快捷方式，双击快捷方式或者浏览器打开 http://localhost:19798。

Linux 通用

  1. 确保你的Linux内核支持fuse，可以通过查看是否存在 /dev/fuse 来检查是否支持fuse，内核不支持fuse将无法挂载本地目录
  2. 如果你需要以非root用户运行CloudDrive，请按照对应操作系统手册安装fuse3，安装好后确认fusermount3命令可以运行，并修改 /etc/fuse.conf，确保user_allow_other这一行前面的注释符#已经被删除掉
  3. 访问我们的官方网站下载对应架构的CloudDrive。
  4. 打开终端并导航到下载的安装包所在的目录。
  5. 运行以下命令以展开 CloudDrive：
    tar zxvf clouddrive-2-linux-$ARCH-$VERSION.tgz
  6. 进入展开后的目录，运行：
    ./clouddrive
  7. 可以将clouddrive运行加入系统自启动，或者设置为系统服务，具体操作请参考操作系统帮助

Arch Linux

  1. Arch Linux 及其衍生版可以通过 AUR 包安装：
    yay -Syu clouddrive
  2. 通过 systemd 设置 clouddrive 启动并开启自启：
    # root 权限
    systemctl enable --now clouddrive.service

    # 用户权限
    systemctl --user enable --now clouddrive.service
  3. 通过默认浏览器打开：
    xdg-open http://localhost:19798

macOS

  1. 运行前请确保系统已安装 macFUSE，并已按照提示正确设置权限
  2. 访问我们的官方网站下载对应架构的CloudDrive。
  3. 打开终端并导航到下载的安装包所在的目录。
  4. 运行以下命令以展开 CloudDrive：
    tar zxvf clouddrive-2-macos-$ARCH-$VERSION.tgz
  5. 进入展开后的目录，运行：
    ./clouddrive

Android

  1. 下载后缀为.apk的安装包安装后执行
  2. 未root的系统将无法挂载本地文件系统，其它功能包括多云盘备份和WebDAV服务等仍然可以正常使用

注册与登录

注册

  1. 第一次运行CloudDrive
  2. 打开CloudDrive，点击右上角的"注册"按钮。
  3. 输入您的邮箱地址和密码，点击"注册"按钮。
  4. 系统将发送一封验证邮件到您的邮箱，请按照邮件中的提示进行操作。
  5. 验证成功后，您将被重定向到登录页面。

登录

  1. 打开CloudDrive，点击右上角的"登录"按钮。
  2. 输入您的邮箱地址和密码，点击"登录"按钮。
  3. 如果您的账号已经通过验证，您将被重定向到CloudDrive的主页。

云盘设置

添加和配置各种云存储服务到CloudDrive中。

添加云盘

点击左侧菜单的"+"按钮，选择要添加的云盘类型，输入认证信息。

云盘配置

可以设置上传/下载限速、缓存策略、代理等高级选项。

本地挂载

将云盘挂载为本地磁盘，像使用本地文件一样访问云端文件。

提示：挂载后可以在文件管理器中直接访问云盘文件，支持所有本地应用程序。
  1. 在云盘列表中找到要挂载的云盘
  2. 点击右侧的"挂载"按钮
  3. 选择挂载点路径
  4. 配置挂载选项（可选）
  5. 点击"确认挂载"

备份功能

多云盘备份

将文件同时备份到多个云盘，确保数据安全。

版本管理

保留文件的多个版本，支持恢复到历史版本。

WebDAV服务

CloudDrive可以作为WebDAV服务器，为其他设备和应用程序提供文件访问服务。

访问地址
http://<CloudDrive服务器IP>:19798/dav/

在支持WebDAV的应用中使用此地址连接到CloudDrive。

故障排除

无法访问管理界面

检查防火墙设置，确保19798端口未被阻止。

挂载失败

确认系统支持FUSE，检查挂载点权限设置。

网络连接问题

检查网络连接，配置代理设置（如需要）。

登录失败

检查邮箱和密码是否正确，确认账号已验证。
