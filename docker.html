部署指南

在 Docker 里跑 CloudDrive2

镜像是 cloudnas/clouddrive2。容器里的挂载要能在宿主机上看见， 启动之前需要先把共享挂载传播打开——这一页从头到尾就是这件事， 以及一份可以直接复制的启动配置。

运行前准备

先打开共享挂载

这一步不能跳过。没有共享挂载，容器里的挂载会直接失败并报「权限被拒绝」。

CloudDrive 用 fuse3 挂载云存储。在 Docker 容器里使用 fuse3 时，需要在宿主机上启用共享挂载—— 可以在 Docker 服务配置里设置 MountFlags，也可以在宿主机上执行 mount --make-shared。这是因为 fuse3 需要共享挂载才能正常工作， 没有共享挂载时挂载会失败并显示「权限被拒绝」的错误。启用共享挂载之后， fuse3 的挂载点就能在 Docker 容器和宿主机之间共享，云存储也就能被无缝访问。

两个选项，按 Docker 的运行方式选一个即可。

选项 1 · Docker 以 systemd service 运行

在 Docker 服务中启用 MountFlags：

sudo mkdir -p /etc/systemd/system/docker.service.d/
sudo cat <<EOF > /etc/systemd/system/docker.service.d/clear_mount_propagation_flags.conf
[Service]
MountFlags=shared
EOF
sudo systemctl restart docker.service

选项 2 · Docker 不是以 systemd service 运行

在宿主机上直接启用共享挂载选项：

sudo mount --make-shared $(df -P /path/to/dir | tail -1 | awk '{ print $6 }')
选项 2 重启后会失效

mount --make-shared 只在当前运行的系统中生效，重启后需要重新执行。 如需重启后自动运行 CloudDrive，请把这条命令加入系统启动项。

使用方法

启动容器

Compose 与 CLI 两种写法等价，任选一种。

Docker Compose

version: "2.1"
services:
  cloudnas:
    image: cloudnas/clouddrive2
    container_name: clouddrive2
    environment:
      - TZ=Asia/Shanghai
      - CLOUDDRIVE_HOME=/Config
    volumes:
      - <path to accept cloud mounts>:/CloudNAS:shared
      - <path to app data>:/Config
      - <other local shared path>:/media:shared #optional media path of host
    devices:
      - /dev/fuse:/dev/fuse
    restart: unless-stopped
    pid: "host"
    privileged: true
    network_mode: "host"

Docker CLI

docker run -d \
    --name clouddrive \
    --restart unless-stopped \
    --env CLOUDDRIVE_HOME=/Config \
    -v <path to accept cloud mounts>:/CloudNAS:shared \
    -v <path to app data>:/Config \
    -v <other local shared path>:/media:shared \
    --network host \
    --pid host \
    --privileged \
    --device /dev/fuse:/dev/fuse \
    cloudnas/clouddrive2

三个需要你自己填的路径

  • <path to accept cloud mounts> → /CloudNAS:shared

    云盘挂载出现的位置。带 shared 标记，挂载才能传播回宿主机。

  • <path to app data> → /Config

    配置与数据目录，对应环境变量 CLOUDDRIVE_HOME=/Config。容器重建后配置要还在，这个卷就不能少。

  • <other local shared path> → /media:shared

    可选。宿主机上的其他本地目录，需要在 CloudDrive 里一起管理时才加。

配置

打开管理界面

http://<ip>:19798

容器跑起来之后，用浏览器访问宿主机的这个地址，就能注册账号、添加云存储、 设置挂载点。后面所有事情都在这个界面里完成，详见帮助。
