怎么接进去的

开机就有账号，不用注册

认证设备出厂时带一个唯一的设备 ID，CloudDrive2 拿它直接建账号，把注册这一步整个省掉。这样建出来的账号不缺任何功能，和你自己用邮箱注册的完全一样。

  1. 设备出厂带 ID

    每台认证设备有一个唯一的设备 ID，厂商在出厂前和我们登记好。

  2. 开机就是账号

    第一次打开 CloudDrive2，它拿这个 ID 建好账号，不填邮箱，也不用等验证码。这台设备在我们这边记为「受信任设备」。

  3. 随时换成自己的邮箱

    在「个人资料」页用「修改邮箱和密码」一步换成自己的邮箱和密码，换完这个账号在手机、电脑、电视上都能登录。

用设备 ID 建的账号，注销前要先设置真实的用户名和邮箱

注销账号需要一个能验证到本人的邮箱，所以设备 ID 账号得先在「个人资料」里补上用户名和邮箱，才能走注销流程。这一步顺手也就把账号变成了你自己的。

合作

我们对所有厂商开放

不管你做的是 NAS、电视盒子、播放机还是头显，只要想把 CloudDrive2 放进产品里，都可以直接找我们。正式对接之后能拿到这些。

  • 设备 ID 注册通道

    你的设备可以用设备 ID 直接建号，用户开机即用，省掉注册和验证邮箱这一步。

  • 认证与露出

    进这个页面的名单。用户能确认自己设备上的 CloudDrive2 是官方对接的版本，不是随手打包进去的。

  • 技术对接

    预装、启动参数、Docker 与 Linux 上的部署方式，以及 gRPC API——想把 CloudDrive2 接进自家界面也可以。

  • 硬件适配

    遥控器界面、解码能力、挂载权限这些跟硬件相关的问题，可以直接提给我们，不用绕社区。
