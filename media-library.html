媒体库

选择云盘中的文件夹，CloudDrive2 应用就把其中的电影、剧集、音乐和图书整理成带海报、简介和演员的媒体库。不需要另外搭建 Emby、Jellyfin 或 Plex 服务器：文件夹里已有的 NFO 和图片优先使用，缺少的信息可以从 TMDB 等网站获取；已经有 Emby 或 Jellyfin 服务器的，可以直接导入它的媒体库。整理结果保存在你自己的设备上，并可以通过你自己的云盘在多台设备之间同步。

类型

五种媒体库

一个媒体库由一个或多个文件夹组成，可以来自任何云盘、WebDAV、NAS 或本地文件夹，只要 CloudDrive2 能列出它们。不同媒体库的文件夹可以重叠。

剧集剧集、季和集，包括动画NFO 和图片，TMDB，动画还使用 Bangumi海报墙、季、集、接下来

在哪里显示

媒体库显示在应用的「影视」界面中，名为「CloudDrive 媒体库」，与 Emby、Jellyfin 服务器并列。在「设置 → 界面」中选择「影视」，应用启动后先显示海报墙。

  • 首页：精选、继续观看、接下来、继续收听、继续阅读，以及每个媒体库的「最新」一行。正在扫描或同步的媒体库显示状态，例如「扫描中」「识别中」「同步中」；由另一台设备扫描时显示「他处扫描」或「等待中」，见由一台设备扫描。
  • 精选：首页顶部的轮播，显示继续观看、接下来和各媒体库最新的影片。私密媒体库锁定时，以及家长控制锁定时超过最高分级的影片，不会出现在精选中。
  • 搜索：片名的译名和别名也能搜到，繁体和简体、重音符号不影响结果。歌曲在所在专辑的页面打开过之后才能搜到。
  • 收藏：收藏与媒体库数据分开保存，「清除媒体库数据」和重新扫描不会删除，并随跨设备同步媒体库同步。

哪些设备可以使用

iPhone、iPad、Mac、Windows 电脑、Apple TV、Apple Vision Pro、Android 手机、平板和电视、Meta Quest 上的 CloudDrive2 应用。每台设备都在本机整理媒体库，不需要一直开着的服务器。

各设备上的功能相同，但有这些差别：Meta Quest 没有 Emby 兼容接口；Apple TV 上不能从 Emby 或 Jellyfin 导入，其他设备导入的媒体库会同步过来；Apple TV 和 Android TV 的人物页不显示链接，「重新扫描」没有自定义间隔；Apple TV 上「编辑元数据…」只能改文字，Android TV 上的图片只能来自云盘；Android 没有选择视频轨的功能，也没有选择多个项目和右键菜单。较小的差别会在相关处注明。

核心服务的网页管理界面不显示媒体库，但提供「媒体库待确认」页面，可以在浏览器中确认自动识别无法确定的影片，见在网页上确认。

App Pro

整个媒体库功能都需要 App Pro：添加和编辑媒体库、在线信息、识别、保存信息和图片、跨设备同步，以及在「影视」界面中浏览和播放。

识别

这些设置只保存在本设备，不同步。

  • 从 TMDB 获取影片信息：默认关闭。打开后，没有 NFO 的影片从 TMDB 获取海报、简介和演员。不需要自己申请 API 密钥。

  • 从 MusicBrainz 获取音乐信息：默认关闭。找到专辑的年份，补上缺少的封面，还找到具体的发行版本和演职人员；艺术家页的简介和照片来自维基百科和维基共享资源。

导入

从 Emby 或 Jellyfin 导入

Emby 或 Jellyfin 服务器的媒体文件就在你的网盘中时（例如通过 CloudDrive2 挂载），可以把服务器的媒体库导入：影片的信息、图片、媒体信息、观看记录和人物都从服务器读取，不再扫描文件夹、不再刮削，影片直接从网盘播放。导入只读取服务器，不修改服务器上的任何内容。

只支持媒体文件本身在网盘中的服务器。用 .strm 文件指向媒体的媒体库暂时不能导入。

如何导入

  1. 先在「媒体服务器」中登录这台服务器。只有服务器的管理员才能读取媒体库的文件夹。
  2. 在「设置 → 媒体库」中点「从 Emby 或 Jellyfin 导入…」，选择服务器。
  3. 列出服务器的媒体库和其中每个文件夹。位于本设备网盘中的文件夹显示「可从 … 直接播放」；不在网盘中的（服务器自己的硬盘或 NAS）显示「不在本设备的网盘中」，不导入。对应的网盘文件夹由服务器上的 CloudDrive2 配套插件、同名的网盘账号，以及你在「媒体服务器」中为这台服务器设置的路径映射得出。
  4. 勾选媒体库，选择导入哪些人物、CloudDrive 已有信息时以哪一方为准，然后点「导入」。导入在后台进行，可以关闭窗口，「设置 → 媒体库」中显示进度。导入过的媒体库显示「更新」，再导入一次就是更新它。

服务器的电影库成为电影库，剧集库成为剧集库，其他视频库成为混合库。音乐库和图书库暂时不能导入。

CloudDrive 已有信息时

影片和人物分开选择：「优先使用服务器的信息」（影片的默认）、「优先使用 CloudDrive 的信息」、「使用有内容的一方，两边都有时使用较新的」（人物的默认）。空白内容不会替换已有内容，CloudDrive 的信息也不会被删除。下次导入同一台服务器时沿用上次的选择；影片的选择也可以在媒体库编辑页面的「从 某服务器 导入」一行中更改，不需要重新读取。

导入的内容

  • 电影和剧集的名称、原名、简介、标语、类型、标签、制作公司、分级、评分和首映日期；海报、标志、横幅、缩略图和所有背景图，显示时从服务器获取。
  • 剧集的季和集，每一集的名称、简介、编号、时长和播出日期。
  • 服务器读到的媒体信息：分辨率、HDR 和杜比视界、音轨（包括全景声和 DTS:X）、字幕。服务器没能读取的文件，例如部分 ISO，由应用在后台检测。
  • 你在服务器上的观看记录、播放进度和收藏（导入时登录的用户的），设备上更新的记录保留。
  • 人物：「这些媒体库中有简介或照片的人物」（默认）、「这些媒体库中的所有人物」、「服务器上的所有人物」或「不导入人物」。简介、生卒日期、出生地、照片和最多 6 张背景图，以及标签和一句话介绍。照片下载到本设备。

导入之后

  • 导入的媒体库从服务器读取，不扫描文件夹，也不在线查询，首页和媒体库页显示「正在从 某服务器 读取 · 已读取 N 部」。每次重新扫描时再读一次服务器，服务器上已经没有的影片会去掉。
  • 开启跨设备同步媒体库和同步扫描数据时，导入的媒体库同步到你的其他设备，它们使用导入它的设备读到的内容；人物的简介、照片和前三张背景图也一起同步。没有登录这台服务器的设备上，服务器的图片显示不出来时改用其他图片。
  • Apple TV 上没有导入，可以显示其他设备导入的媒体库。

识别

视频如何识别

整理视频时只读取文件夹和文件的名称，不打开视频文件。常见的命名方式都能识别，包括下载站和发布组的长名称、字幕组的命名、中文数字的集数、蓝光原盘和 DVD、分成几段的电影和成套的光盘，文件不需要先改名。

不单独成为影片的文件

  • 花絮和预告片属于所在的影片，例如 trailers、featurettes 文件夹，名称以 -trailer 结尾的文件，以及字幕组的 [NCOP]、[NCED]。
  • NAS 和系统的文件夹不读取，例如 @eaDir、#recycle、$RECYCLE.BIN。
  • 名称带「测试」「样片」「demo」等词的视频按测试片段处理，不在线查找。
  • 同一个媒体库中同一部电影的几个文件合并为一部电影，在详情页的版本中选择。

在名称中指定条目

文件或文件夹名中的 {tmdbid=123}、[tmdb-123]、(imdb-tt0113277)，或 MoviePilot 的 {[tmdbid=123;type=tv;s=2]}，直接指定 TMDB 或 IMDb 条目，不再搜索。识别不对时，也可以在「识别…」中手动选择，或用识别词修正一批文件。

视频文件

mkv、mp4、m4v、mov、avi、wmv、flv、webm、mpg、mpeg、m2ts、mts、ts、vob、rmvb、rm、3gp、ogv、iso。

刮削

刮削与匹配

识别出片名和年份后，从 TMDB 获取影片的信息和图片，动画同时在 Bangumi（番组计划）查找。不能确定是哪一部的影片进入待确认，确认之前照常可以播放；你在「识别…」中的选择不会被自动识别覆盖。

已有的 NFO 和图片

Kodi、Emby、Jellyfin、tinyMediaManager 等工具写入的 NFO、海报、背景图、标志和季海报都会读取。NFO 中有 TMDB 或 IMDb 编号时，按编号直接获取，不再搜索。

文件夹中的 NFO 和图片优先显示，TMDB 只补充缺少的部分；媒体库打开「优先使用在线信息」时相反。你用「编辑元数据…」保存的内容总是优先。

从 TMDB 获取的信息

片名、简介、类型、评分、海报和背景图、演员和导演、每一季和每一集的信息、合集，以及用于家长控制的分级。显示的语言由媒体库的「信息语言」决定。

动画

确认

待确认与手动识别

自动匹配无法确定的影片进入「待确认」，确认之前照常可以从文件播放。媒体信息检测发现的问题也列在这里：无法读取的文件，以及文件时长与自动匹配到的影片相差较多的。

「识别…」

每部影片的详情页都有「识别…」：可以从最多 5 个候选中选择，搜索片名和年份，标记「不在 TMDB 上」，或「重新自动识别」。识别结果是自动匹配的时，「保留这个结果」把它确认为你的选择。

手动选择会一直保留，自动识别不会覆盖它；开启跨设备同步时，其他设备也采用这个选择。媒体库的「在线查找」关闭时也可以手动识别。

识别专辑和图书

专辑页的「识别专辑」和图书页的「识别图书」在 MusicBrainz 或 Open Library 上选择正确的条目，补上缺少的年份和封面。选择随媒体库同步。

AI 辅助识别

规则无法识别的影片、专辑和图书，可以使用 AI 模型辅助识别。在「设置 → 媒体库 → 识别 → AI 辅助识别」中选择服务、模型和 API 密钥（与 AI 字幕使用同一个密钥），并选择模型读取哪些媒体库。私密媒体库和关闭了「在线查找」的媒体库不能选择。

  • 模型读取项目在媒体库文件夹以下的路径和从文件中读到的信息，只给出搜索词；之后照常在 TMDB、MusicBrainz 和 Open Library 中搜索，并按上面的规则确定结果。
  • 打开后，在后台为未识别的项目询问模型，每个项目的回答保存在设备上，每天最多调用 1,000 次。
  • 「识别…」中的「询问 AI」显示模型的回答和依据。选择结果之前不会保存任何内容。

在网页上确认

核心服务的网页管理界面中有「媒体库待确认」页面，适合在电脑浏览器中处理电视上积累的待确认影片。

  • 需要至少一台设备开启了跨设备同步媒体库。网页读取各台设备上传到「CloudDrive2 Sync」文件夹的待确认列表。
  • 可以选择候选，或粘贴 TMDB 链接或编号；网页没有片名搜索。
  • 你的设备下次同步时采用网页上的选择。
  • 私密媒体库的影片在输入 PIN 解锁后显示。

识别词

识别词

识别词在读取之前改写这个媒体库里的文件名和文件夹名：纠正季、集的编号，把片名替换为指定的名称，去掉广告前缀。格式与 MoviePilot 的自定义识别词相同，已有的列表可以直接粘贴。每行一条规则，按顺序执行；以 # 开头的行是备注。

# 删除词语
国语中字
# 替换（(?i) 表示不区分大小写）
(?i)Kimetsu no Yaiba => 鬼灭之刃
# 调整两个词之间的集数
第 <> 集 >> EP+12
# 先替换，再调整集数
Apotheosis.S02 => Apotheosis S01 && S01 <> 2160p >> EP+52
# 把名称指向 TMDB 条目，可以指定季和集
斗罗大陆 => 斗罗大陆{[tmdbid=99025;type=tv]}
  • =>、&&、<>、>> 两侧需要空格。调整集数时，前后的定位词可以有一个为空。
  • 规则是正则表达式，对照名称原文匹配，包括扩展名；默认区分大小写。
  • 调整集数时，两个词之间的每个数字都会改变；表达式支持 EP、整数和加减乘除。数字前面的 0 会保留（05 加 12 是 17），中文数字仍写成中文。
  • {[…]} 中可以写 tmdbid、imdbid、type（movie 或 tv）、s（季）、e（集）。
  • 最多读取 1,000 行，每行最多 1,000 个字符。
  • 识别词只在这个媒体库中生效：文件管理、播放器和字幕中显示的仍是原来的名称，文件也不会被改名。
  • 编辑器逐行检查，例如「第 4 行未使用：…」。「试一个名称」显示改写后的名称、是哪几行改的，以及读取出的片名、年份、季和集。
  • 修改识别词后，媒体库重新整理；NFO 中的信息和观看进度保留。
  • 「导出」保存为 <媒体库> 识别词.txt（UTF-8）。「导入」支持 UTF-8 和 GB18030 编码的文件，可以选「添加到末尾」（跳过已有的行）或「替换」。电视上可以用手机输入整段文字。
  • 识别词随媒体库同步，以最后一次编辑为准。

媒体信息

媒体信息

媒体信息是视频文件本身的技术信息：分辨率、帧率、HDR、编码、音轨和字幕。它用于详情页的媒体信息卡片、海报角标和「画面与声音」筛选。检测只读取文件开头的一小部分，不下载整个文件。

来源

  • 由文件名推测：每部影片先按文件名推测分辨率、HDR、编码和音轨（如 2160p、DV、Atmos）。
  • 来自 NFO：NFO 中的 <streamdetails>。
  • 检测媒体信息：读取文件开头，支持 MKV、MP4、TS 和 M2TS，一部 2 小时的电影通常只读取 128–320 KB；蓝光 ISO 和 BDMV 文件夹从播放列表读取正片的信息。
  • 播放时保存：播放媒体库中的视频几秒后，保存播放器读到的信息。

能读出编码、分辨率、帧率、HDR10、HDR10+、HLG 和杜比视界、杜比全景声、DTS-HD MA 和 DTS:X，以及音轨和字幕的语言。结果按文件的大小和修改时间保存，文件改变后重新检测。

用途

媒体信息用于海报上的 4K、杜比视界、HDR、全景声角标（检测过的为实心，仅由文件名推测的为空心）、「画面与声音」筛选、一部电影有多个版本时选择最适合本设备的版本，以及在待确认中列出无法读取或时长不符的文件。开启「在媒体旁保存信息和图片」时，检测结果也写入 NFO。

识别时检测

每个视频媒体库的「识别时检测媒体信息」默认开启：扫描这个媒体库的设备在识别影片的同时读取视频文件的开头，最新的影片先检测，一个文件通常只读 256 KB 左右。开启跨设备同步扫描数据时，结果同步到其他设备，它们不再读取。

后台检测媒体信息

用于关闭了「识别时检测媒体信息」的媒体库。在「设置 → 媒体库 → 扫描与存储」中打开，默认关闭，只对本设备有效。它逐个、缓慢地读取每个视频文件的开头：读完一个文件后按「文件之间的间隔」等待（云盘默认 2 秒），播放视频时暂停。

人物与合集

人物、合集与编辑

演员、艺术家和作者有自己的页面；属于同一合集的电影可以一起浏览；电影和剧集的信息可以手动修改。

人物页

  • 演员和导演：简介、照片和链接来自 TMDB，按媒体库的信息语言获取；页面列出媒体库中有这个人的影片。
  • 艺术家：简介和照片来自维基百科和维基共享资源，通过 MusicBrainz 给出的链接获取。
  • 作者：简介来自 Open Library 和维基百科。
  • 同一个人在 NFO、TMDB 和音乐、图书的演职人员中是同一条记录，各种语言的名字都能找到这个人。
  • 其他应用通过 Emby 兼容接口写入的名字、简介和照片优先显示。

合集

TMDB 的合集，或 NFO 中的 <set>，把电影归入合集。媒体库中有两部以上电影的合集，出现在二级分类按钮中的「合集」里。

编辑元数据

电影和剧集的详情页有「编辑元数据…」，可以修改标题、简介、类型、演员和图片等。修改保存为影片文件夹里的 NFO 文件和图片，所以其他应用和你的其他设备也会读取；只修改你改动的部分，其他应用写入的内容保留。手动编辑的内容优先于在线信息，「优先使用在线信息」也不会替换它。Apple TV 上不能修改图片。

播放

跳过片头片尾

播放媒体库中剧集的一集时，可以在播放器中设置这一季的片头在哪里结束、片尾从哪里开始。设置对这一季的每一集都有效，并随跨设备同步媒体库同步到你的其他设备。

设置

  • 播放媒体库中剧集的一集时，在播放器的「片头片尾」中，播放到片头结束或片尾开始的地方点「设为当前位置」。
  • 片头从每一集的开头算，片尾从每一集的结尾倒着算，所以长度不同的各集也能用同一个设置。
  • 「跳过片头片尾」开关只对这台设备有效，默认打开；关闭后不跳过，设置的时间保留。

播放时

  • 从头播放一集时跳过片头；播放到片尾开始的地方时接着播放下一集，这一集算作看完。
  • 手动把进度拖到片头或片尾之内时照常播放。

哪些设备

Mac、iPhone、iPad、Apple TV、Apple Vision Pro（窗口播放和沉浸式播放）、Android 手机、平板和电视、Meta Quest、Windows 电脑。

  • 私密媒体库开启前会提示：片名、简介和海报会作为普通文件保存，能打开这些文件夹的人和存储服务商都能看到。锁定时不写入。

整理和更新

  • 第一次扫描时，找到的内容陆续出现，不需要等整个媒体库整理完。
  • 没有改变的文件夹不会重新列出。列出文件夹的速度见避免网盘限制账号。
  • 通过这台设备的 CloudDrive2 改名或移动文件时，影片的识别结果随文件移动。

什么时候重新扫描

  • 完整扫描过的媒体库不会再自动扫描。可以在媒体库设置的「重新扫描」中设置自动扫描的间隔，或用「立即扫描」「扫描此文件夹」手动扫描。
  • 第一次扫描被中断时，下次启动从中断处继续，直到完成。

自动发现新文件

账号有核心 Pro 功能文件变更通知时，通过这台设备的 CloudDrive2（应用、网页管理界面、WebDAV、挂载盘）添加、删除、改名的文件，通常在几秒内更新到媒体库，不需要重新扫描。

115、百度网盘和 123 云盘在文件夹内容改变时更新文件夹的修改时间，所以在其他地方添加的文件也能在下次整理时发现。其他云盘上由别的设备或网盘自己的应用做的改动，点「刷新」，或用「扫描此文件夹」「立即扫描」时出现。

本机数据

「设置 → 媒体库 → 扫描与存储」显示媒体库数据和图片占用的空间。「图片上限」可选 500 MB、1 GB、2 GB、5 GB、10 GB、50 GB、100 GB 或不限。「清除媒体库数据」删除已读取的条目、详细信息和图片，然后重新读取媒体库；媒体库、识别结果和观看进度都会保留。

离线时

网站无法访问时使用已缓存的信息。媒体库数据库中的内容在启动时立即显示，无法访问的云盘或文件夹不会让媒体库变空。

避免网盘限制账号

列目录太快或下载太多时，网盘可能限制账号。CloudDrive2 扫描时已经尽量避免：按「列目录速度」列出文件夹，默认每秒 2 次，同时最多列出 3 个文件夹；读取音乐标签时，每个网盘账号每秒最多读取一个文件；检测媒体信息时只读取文件开头的一小部分，通常几百 KB。

这些限制只在一台设备上有效。多台设备同时扫描同一个网盘账号时，请求会叠加，CloudDrive2 无法阻止。所以最好不要在多台设备上扫描同一个网盘账号中的媒体库。同时打开「跨设备同步媒体库」和「跨设备同步扫描数据」后，一个媒体库只由一台设备扫描，其他设备使用它的结果，见由一台设备扫描。

建议把媒体文件和同步数据保存在不同的网盘账号中，这样扫描媒体库和同步数据的请求不会落在同一个账号上。例如媒体文件放在 115 网盘，「CloudDrive2 Sync」文件夹放在 123 云盘。

同步

跨设备同步媒体库

在一台设备上创建媒体库、选择识别结果，其他设备自动得到同样的媒体库。打开「设置 → 媒体库 → 同步 → 跨设备同步媒体库」。这是 App Pro 功能，默认关闭，与同步播放进度使用同一个「CloudDrive2 Sync」文件夹：先开启的那个选择云盘，另一个直接使用，不再询问。建议选择与媒体文件不同的网盘账号，见避免网盘限制账号。数据保存在你自己的云盘中，不经过 CloudDrive 的服务器。

同步的内容

  • 每个媒体库的全部设置，包括文件夹、识别词、二级分类和扫描它的设备；删除媒体库也会同步。
  • PIN 校验信息（不是 PIN 本身）。
  • 影片、专辑和图书的识别结果，包括你的选择。
  • 收藏，以及每一季跳过片头片尾的时间。
  • 待确认的列表，供网页使用。

不同步的内容

  • 媒体库数据和图片：由跨设备同步扫描数据同步，那是单独的开关。
  • 只对本设备有效的选项，例如在线信息的开关、列目录速度、图片上限和家长控制。
  • 观看进度和已看标记：由同步播放进度同步。

如何合并

每一项设置单独合并，以最后修改的为准；你的选择总是优先于自动识别的结果。删除的媒体库不会再出现。较新版本应用写入的文件会被跳过，并提示更新应用。

什么时候同步

应用启动、回到前台和打开媒体库时读取，修改后几秒内上传。云盘限制请求频率时，至少等待 15 分钟再试。在有回收站的云盘上，被替换的旧文件会进入回收站，见不同云盘的差别。

新设备加入

新设备需要登录同一个 CloudDrive 账号，并能访问保存「CloudDrive2 Sync」的云盘，然后打开「跨设备同步媒体库」。媒体库的文件夹按 CloudDrive2 中的完整路径保存，通过「与云端同步」在各设备上都有的云盘路径相同。关闭同步时，媒体库保留在这台设备上，可以选择同时删除这台设备在云盘中的文件。App Pro 是一次性购买，不会到期；只有购买被退款时才会失效，此时同步暂停，云盘中的文件不会被删除。

同步

跨设备同步扫描数据

一台设备列出文件夹、读取文件中的信息、在线查找影片后，可以把得到的结果分享给其他设备，其他设备不再重复读取和查找。一台设备完整扫描过的媒体库，在其他设备上直接可用，新设备几分钟内就能显示很大的媒体库。打开「设置 → 媒体库 → 同步 → 跨设备同步扫描数据」。这是 App Pro 功能，默认关闭，与跨设备同步媒体库使用同一个「CloudDrive2 Sync」文件夹。数据保存在你自己的云盘中，不经过 CloudDrive 的服务器。

设备分享的内容

  • 从文件中读取的信息：NFO、媒体信息、音乐标签、CUE、SACD 光盘文本和图书的元数据。
  • 每个文件夹的整理结果，以及完整扫描过的媒体库的影片列表。取得列表的设备直接显示整个媒体库，只在发现变化或你要求扫描时，才重新读取变化的部分。
  • 在线查找的结果，包括待确认和未找到的，以及人物的详情。
  • 私密媒体库的数据也会同步：「私密」只在媒体界面中隐藏这些媒体库，不限制对云盘的访问。

不同步的内容

  • 图片：由下面的图片包分享。
  • 各设备自己的选项，例如图片上限和在本设备缓存文件。

什么时候同步

应用启动时、回到前台超过 10 分钟时读取；一次扫描或一轮在线查找有新内容时写入。数据包和图片等到连上 Wi-Fi 或有线网络再同步，除非打开「使用移动数据同步」。

关闭同步

已取入的内容保留在这台设备上。也可以同时从云盘删除这台设备的数据包和图片文件。

新设备加入

登录同一个 CloudDrive 账号，确认能访问保存「CloudDrive2 Sync」的云盘，然后打开「跨设备同步媒体库」和「跨设备同步扫描数据」。媒体库的文件夹按 CloudDrive2 中的完整路径保存，所以这个云盘在新设备上需要有相同的路径。其他设备完整扫描过的媒体库直接可用，例如一台新的 iPad 在约一分钟内显示了 Mac 上 7 个视频媒体库的全部影片。

先同步，再扫描

应用启动、打开同步或添加媒体库时，先取回其他设备的扫描数据，再扫描和识别，只处理数据包中还没有的部分。最多等待 5 分钟；离线或读取失败时照常扫描。

谁能读取数据包

数据包是压缩的，没有加密，包含影视的路径、NFO 文件的内容、从媒体文件中读到的信息，以及 TMDB、MusicBrainz 等服务的查询结果。能打开这个云盘的人都能读到，包括私密媒体库的数据。

由一台设备扫描

同时打开两个同步开关时，一个媒体库由一台设备扫描，其他设备等待它的扫描结果，不再各自列出同样的文件夹。创建媒体库的设备默认扫描它，可以在媒体库设置的「在本设备上扫描此媒体库」中改为另一台设备。

  • 扫描期间，扫描的设备至少每 10 分钟上传一次数据包；其他设备显示「正在 某设备 上扫描」，并取入它陆续找到的内容。
  • 扫描的设备 30 分钟没有上传数据包（关机、离线）时，由其他设备继续扫描，已经得到的内容不会丢失。
  • 在本设备点「立即扫描」「扫描此文件夹」或「刷新」总是马上扫描。
  • 图书库扫描只要几秒，每台设备自己扫描。

图片包

逐张从云盘获取海报很慢。打开下载图片包后（需要先打开跨设备同步扫描数据），设备从你的其他设备写入的几个大文件中取得海报和封面，不再逐张获取。手机、平板、电脑和 Quest 上默认开启，Android TV 和 Apple TV 上默认关闭。

  • 写入图片包的设备：打开了「分享图片」（默认打开）、本身有这些图片的设备，只在其他设备请求时写入。
  • 图片包的内容：海报、季海报和封面，不包含背景图和人物照片。
  • 下载哪些图片：本设备显示的媒体库中、本设备还没有的图片，最新的影视在前，直到图片上限用到 90%。下载会等到连上 Wi-Fi 或有线网络，播放视频时暂停。
大型媒体库需要较长时间

媒体库很大时，第一次同步扫描数据和图片可能需要很长时间，请耐心等待。同步在后台进行，已经显示的内容可以照常使用。

图片缓存在本设备上，可能占用很多存储空间。请在「设置 → 媒体库 → 扫描与存储」中按需要设置「图片上限」：默认 1 GB，可选 500 MB 至 100 GB 或不限；超过上限时，先删除最久没有显示的图片。

私密

私密媒体库与 PIN

私密媒体库输入 PIN 后才显示。锁定时，它和其中的影片不出现在任何列表、首页、继续观看、待确认和数量中。每个 CloudDrive 账号一个 PIN，4 到 8 位数字，在「设置 → 媒体库 → 隐私与家长控制」中设置。

  • 自动锁定：默认离开应用 5 分钟后锁定，也可以设为离开时、15 分钟或 1 小时后。每次启动应用时都是锁定的。
  • 私密媒体库的「在线查找」默认关闭，内容不会发送给 AI 辅助识别的服务。
  • 与私密媒体库重叠的文件夹，在锁定时其他媒体库中也会隐藏重叠的部分。
  • 忘记 PIN：PIN 无法找回。可以删除所有私密媒体库和 PIN，之后重新添加，其中的文件夹和文件都会保留。
PIN 不加密文件

PIN 只是在媒体页面中隐藏私密媒体库，并不限制访问：这些文件夹仍可在文件管理和网盘自己的应用中打开。同步文件中保存的是 PIN 的校验信息（PBKDF2-SHA256，100,000 轮），不是 PIN 本身，但 4 位数字的 PIN 可以被很快试出，请不要把它当作密码使用。

家长控制

家长控制

家长控制让这台设备只能浏览媒体库：进入文件、切换到文件管理器或打开设置时，需要输入 4 位数字的家长密码。在「设置 → 媒体库 → 隐私与家长控制」中打开，需要 App Pro。密码只保存在这台设备上，不同步；它和私密媒体库的 PIN 是两个不同的密码。

锁定时

  • 锁定时不能进入文件、文件管理器和设置；「识别…」、添加和删除媒体库需要输入密码。
  • 离开应用或屏幕关闭时立即锁定；也可以设置输入密码后多久没有操作就重新锁定，默认从不。
  • 忘记密码：输入这台设备上登录的 CloudDrive2 账户的密码，验证通过后设置新密码。

最高分级

可选不限制、G（所有年龄）、PG（8 岁以上）、PG-13（13 岁以上）、R（17 岁以上）。锁定时，高于此分级的影片在所有页面、搜索和首页中隐藏。

  • 分级先取 NFO 中的分级，再取 TMDB 的分级；没有美国的分级时，按英国、德国、法国、日本等其他国家和地区的分级换算。
  • 显示没有分级的影片：默认关闭。还没有分级信息的影片在锁定时隐藏，除非打开此项。
家长控制不加密文件

家长控制只限制这台设备上的 CloudDrive2 应用。文件仍可以通过其他设备、网盘自己的应用或挂载的磁盘打开。没有 App Pro 时，媒体库和影视界面都不能使用，家长控制也不起作用。

其他应用

Emby 兼容接口

Mac、iPhone、iPad、Apple TV、Apple Vision Pro、Android 手机和电视、Windows 电脑上的 CloudDrive2 可以提供 Emby 兼容接口，让 MoviePilot 等工具像连接 Emby 服务器一样连接媒体库，读取其中的影片和人物，并补全演员的名字、简介和头像。在「设置 → 媒体库 → 高级 → Emby 兼容接口」中打开，默认关闭。Meta Quest 上没有这个功能。

设置

  • 端口：默认 29801。iPhone、iPad 和 Apple Vision Pro 上只在应用显示在屏幕上时运行。
  • 仅限本机：只有这台设备上的应用可以连接；关闭时局域网内的应用都可以连接。
  • API 密钥：为每个要连接的应用生成一个，并选择它可以访问的媒体库。私密媒体库只有在用 PIN 解锁后选择「包括隐私库」才能访问。
  • 在 MoviePilot 中，服务器类型请选择 Emby，再填入地址和密钥。

其他应用写入的信息

  • 人物的名字、简介、照片和角色名，以及收藏。人物信息优先于 NFO 和 TMDB 显示。
  • 这些信息保存在本机，不写入媒体所在的文件夹；「清除媒体库数据」和重新扫描不会删除它们。
  • 开启跨设备同步扫描数据时，这些信息和照片同步到你的其他设备。
  • 目前只接收人物的信息和收藏，影片本身的信息和图片暂不接收。
安全

接口在局域网内使用普通 HTTP，请妥善保管密钥。通过它只能访问媒体库中的影片和人物，无法访问你的文件和账号。

隐私

哪些信息离开设备

  • CloudDrive 的服务器：不接收媒体库的任何内容。
  • 信息来源网站：只在对应开关和媒体库的「在线查找」都打开时，发送表格中列出的内容，例如片名和年份。不发送文件内容、路径和账号。打开艺术家或作者页时，MusicBrainz 编号或作者姓名会发送给 Wikidata 和维基百科。
  • 你选择的 AI 服务：只在打开「AI 辅助识别」时，发送所选媒体库中未识别项目在媒体库文件夹以下的路径、文件名，以及从文件中读到的标签、CUE、SACD 文本或 OPF（Windows 不发送目录表、目录编号和 SACD 文本）。私密媒体库的内容不发送。部分服务可能会用免费套餐下发送的内容训练模型；DeepSeek 将数据存储在中国大陆。
  • 你的 Emby 或 Jellyfin 服务器：只在导入时用你的登录读取媒体库、影片、人物、图片和你的观看记录，不写入任何内容。
  • 局域网中的应用：只在打开 Emby 兼容接口时，持有密钥的应用可以读取所选媒体库中的影片和人物。
  • 你的云盘：开启同步时，保存同步文件；开启同步扫描数据时，保存数据包、图片文件，以及其他应用和导入的服务器给出的人物照片；开启保存信息和图片时，保存 NFO 和图片；用「编辑元数据…」保存时，写入影片文件夹的 NFO 和图片。

同步文件是普通的 JSON 文本，不加密，包含媒体库的名称和文件夹、PIN 校验信息、已识别影片的路径和 TMDB 编号、待确认的候选，以及剧集每一季跳过片头片尾的时间。能打开这个云盘的人，包括与你共用这个云盘账号的人和云盘服务商，都可以读取。请选择你愿意保存这些信息的云盘。删除「CloudDrive2 Sync」文件夹会删除云盘中的副本；仍然开启同步的设备会重新写入自己的文件。

扫描数据包是压缩的，没有加密，包含影视的路径、NFO 文件的内容、从媒体文件中读到的信息，以及 TMDB、MusicBrainz 等服务的查询结果，包括私密媒体库的数据；图片文件包含海报和封面。能打开这个云盘的人都能读到。

FAQ

常见问题

媒体库里只有文件名，没有海报和简介

文件夹里没有 NFO 和图片时，需要在线查找。打开「设置 → 媒体库 → 识别 → 从 TMDB 获取影片信息」，并确认这个媒体库的「在线查找」是打开的。私密媒体库的「在线查找」默认关闭。用「测试连接」检查能否访问 TMDB；在中国大陆请使用默认的 api.tmdb.org。

识别错了，怎么改

在影片详情页点「识别…」，从候选中选择，或搜索片名和年份。选择会一直保留。如果一批文件都有同样的问题，例如字幕组的名称或集数编号，可以写一条识别词，或在文件夹名中加上 {tmdbid=…}。

为什么没有年份的电影常在待确认中

同名的电影很多，没有年份时，只有文件名中的中文名和英文名都与同一部电影相符才自动识别，否则需要你确认一次。在文件名或文件夹名中加上年份，例如 Heat (1995)，就可以自动识别。

已经用 tinyMediaManager 或 Emby 刮削过，还需要在线查找吗

不需要。文件夹里的 NFO 和图片优先使用，NFO 中有编号的影片直接识别。可以关闭在线查找，媒体库只显示文件夹里已有的信息。

开启「在媒体旁保存信息和图片」会覆盖我已有的文件吗

不会。其他工具写入的 NFO 和图片不会被改动；文件夹中已有其他工具的 NFO 时，这部影片不写入任何文件。只有同时打开「优先使用在线信息」时，确认后其他工具的 .nfo 和图片会被改名（加上 .bak），替换为 TMDB 的信息和图片，不会删除。

新加入的文件没有出现在媒体库中

在媒体库页面点「刷新」。账号有核心 Pro 功能「文件变更通知」时，通过这台设备添加的文件会自动出现，见自动发现新文件。在其他设备或网盘自己的应用中添加的文件，要等文件夹再次被读取时才出现：在媒体库的文件夹视图或文件浏览器中点「扫描此文件夹」，或在媒体库设置中点「立即扫描」，也可以设置「重新扫描」的间隔。

另一台设备上没有我的媒体库

两台设备都要打开「跨设备同步媒体库」，登录同一个 CloudDrive 账号，并且都能访问保存「CloudDrive2 Sync」的云盘。不开同步时，可以用「导出媒体库…」和「导入媒体库…」。影片列表、从文件中读到的信息和海报，由跨设备同步扫描数据负责。

新设备又把整个媒体库扫描了一遍

在新设备和一台已经扫描过的设备上都打开「设置 → 媒体库 → 同步 → 跨设备同步扫描数据」。另一台设备完整扫描过的媒体库，新设备直接取入，不列出文件夹，不重复读取和查询；同时打开「跨设备同步媒体库」时，新媒体库也只由一台设备扫描，见由一台设备扫描。第一次读取会等到连上 Wi-Fi 或有线网络，除非打开了「使用移动数据同步」。海报由图片包取得，电视上要先打开「下载图片包」。

扫描时网盘提示请求太频繁，或限制了账号

先停止在其他设备上扫描同一个网盘账号中的媒体库，并在媒体库设置中把「列目录速度」改为每秒 1 次。然后同时打开「跨设备同步媒体库」和「跨设备同步扫描数据」，让一个媒体库只由一台设备扫描。建议把「CloudDrive2 Sync」文件夹放在与媒体文件不同的网盘账号中，例如媒体文件在 115 网盘、同步数据在 123 云盘。见避免网盘限制账号。

媒体库会改动或删除我的文件吗

不会删除。媒体库只读取文件夹，删除媒体库或移除文件夹也不会删除文件。识别词只改变媒体库中读取的名称，不会给文件改名。会写入的只有：你开启的「在媒体旁保存信息和图片」、你用「编辑元数据…」保存的 NFO 和图片，以及同步文件。同时打开「优先使用在线信息」和「在媒体旁保存信息和图片」时，其他应用的 .nfo 和图片会被改名为 .bak，不会删除。其他应用通过 Emby 兼容接口写入的信息保存在本机，不写入你的文件。

海报上的 4K、HDR 角标是空心的

空心角标是由文件名推测的，还没有读取文件确认。媒体库的「识别时检测媒体信息」打开时（默认），扫描它的设备会逐渐检测；也可以在详情页点「检测媒体信息」，或在「设置 → 媒体库 → 扫描与存储」中打开「后台检测媒体信息」。检测后角标变为实心。

媒体库显示「他处扫描」或「等待中」

这个媒体库由另一台设备扫描，这台设备直接使用它的结果。想在这台设备上扫描，点「立即扫描」，或在媒体库设置中打开「在本设备上扫描此媒体库」。那台设备关机或离线 30 分钟后，由其他设备继续扫描。见由一台设备扫描。

识别改进后，以前没识别出来的影片怎么办

在媒体库设置中点「重新识别未识别的标题」旁的「重新识别」。待确认、未找到和被当作其他内容的标题会按新的规则重新查找，在所有同步的设备上生效；已识别的和你选择过的不变。按新规则整理文件夹（例如一套光盘）要先「扫描此文件夹」。

每集都要看一遍片头

播放这一季的任何一集时，在播放器中打开「片头片尾」，在片头结束时点「设为当前位置」。整季的每一集都会跳过片头，你的其他设备也一样。见跳过片头片尾。

忘记了家长控制的密码

在输入密码的界面点「忘记密码？」，输入这台设备上登录的 CloudDrive2 账户的密码（开启了两步验证时还要输入验证码）。验证通过后可以设置新密码。

已经用 Emby 或 Jellyfin 整理好了，还要再扫描一遍吗

不用，媒体文件在你的网盘中时可以直接导入（暂不支持 .strm 文件）：在「设置 → 媒体库」中点「从 Emby 或 Jellyfin 导入…」。影片的信息、图片、媒体信息、观看记录和人物都从服务器读取，影片从网盘直接播放，不再扫描文件夹，也不在线查询。见从 Emby 或 Jellyfin 导入。

导入以后，Emby 或 Jellyfin 服务器还要一直开着吗

播放不需要：影片直接从网盘播放。导入的媒体库每次重新扫描时从服务器读取，服务器关闭时保留上次读到的内容；海报和背景图在显示时从服务器获取，获取不到时改用其他图片。人物的照片在导入时已经下载到设备上。

能用 MoviePilot 等工具补全演员头像吗

可以，在 Mac、iPhone、iPad、Apple TV、Apple Vision Pro、Android 手机和电视、Windows 电脑上（Meta Quest 上没有）。打开「设置 → 媒体库 → 高级 → Emby 兼容接口」，为工具生成一个密钥，在工具中把服务器类型选为 Emby，填入服务器地址和密钥。工具写入的名字、简介和头像会优先显示，见 Emby 兼容接口。
