下载

装到你想装的地方

同一套核心，两种装法：电脑、NAS 或 Docker 上装成后台服务，手机、平板、电视和头显上装应用。 用同一个 CloudDrive 账号登录即可。

应用商店

手机、平板、电视与头显

  • App StoreiPhone · iPad · Mac · Apple TV · Vision Pro，即将上架
  • Google PlayAndroid 手机与 Android TV
  • Meta HorizonQuest，内测中
  • Docker Hubcloudnas/clouddrive2

核心服务

直接下载安装包

当前版本：1.0.13 · GitHub 发布页

安装完成后，用浏览器打开 http://<主机 IP>:19798 进入管理界面。 安装步骤见帮助页。

Windows

  • Windows x64CloudDrive2Setup-X64-1.0.13.exe
  • Windows Arm64CloudDrive2Setup-Arm64-1.0.13.exe

Linux

  • Linux x86_64clouddrive-2-linux-x86_64-1.0.13.tgz
  • Linux aarch64clouddrive-2-linux-aarch64-1.0.13.tgz
  • Linux armv7clouddrive-2-linux-armv7-1.0.13.tgz

macOS

需要先安装 macFUSE 才能把云盘挂载成本地磁盘。也可以用 Homebrew 安装，步骤见帮助页。

  • macOS Intelclouddrive-2-macos-x86_64-1.0.13.tgz
  • macOS Apple Siliconclouddrive-2-macos-aarch64-1.0.13.tgz

Android

手机与平板装 APK 即可。tgz 包用于在 Android 设备上运行核心服务。 手机上的本地挂载需要 Root；浏览、播放、备份与 WebDAV 不需要。

  • Android APK（通用）clouddrive-2-android-universal-1.0.13-219.apk
  • Android aarch64clouddrive-2-android-aarch64-1.0.13.tgz
  • Android x86_64clouddrive-2-android-x86_64-1.0.13.tgz
  • Android armv7clouddrive-2-android-armv7-1.0.13.tgz

飞牛官方应用中心上架审核中。目前请下载对应架构的 fpk 包手动安装。

1.0.13(Web3.0.13)
  1. 多网盘备份增加全量扫描资源占用控制功能：
    1. 默认并发备份扫描数为1，可以在备份页面修改最大并发数，超过的备份全量扫描会排队等待
    2. 可以设置上传任务队列上下限，当上传任务数超过设置的上限时，扫描任务会暂停等待，当上传任务数回落到设置的下限时，扫描任务自动恢复，避免因扫描大文件造成太多上传任务堆积，默认为不限制，可以在备份页面修改
  2. 跨云盘复制时，可在系统设置下载上传页面设置是否在计算哈希阶段将下载的数据保存到临时文件，上传时将无需再次下载源文件，复制完成后临时文件自动删除，该选项默认为关闭
  3. Windows版修复在系统文件管理器对挂载盘图片编辑时可能出错，执行图片旋转后缩略图不自动刷新的问题
  4. 修复Web界面实时显示的任务数可能不准确的问题
  5. Web界面修复把本地文件拖动到根目录会产生一个无法完成的上传任务，并且创建一个无法删除的文件的问题

1.0.7(Web3.0.7)

⚠️ 重要安全提示（Windows 用户必读）

本版本将 WinFSP 升级至 2026 beta1，以修复旧版本 WinFSP 中发现的安全漏洞 CVE-2026-3006。

  • 请务必下载完整安装包重新运行安装程序，并按安装向导提示重启系统。
  • 请勿使用应用内 OTA 升级：OTA 仅替换 CloudDrive2 程序文件，不会重新安装 WinFSP 驱动，将无法获得本次安全修复。
  1. 115网盘配置界面最大下载线程数限制为2，设置的值不能超过2
  2. 115网盘配置界面增加每秒最大请求数限制，最大不能超过5.0
  3. SMB/SFTP/FTP新增支持获取磁盘空间大小（仅部分 FTP 服务端支持，目前已知 Pure-FTPd 与启用 mod_facts 的 ProFTPD 可正确返回，其它服务端将回退为占位值。受协议限制，AVBL 只返回可用字节数，因此总容量与可用相同、已用显示为 0）
  4. 改进smb服务器和共享发现算法，适应更多场景
  5. 文件重命名冲突处理方式改进：
    • 核心层(webdav/http/clouddrive共享等)的重命名冲突从原来的直接覆盖旧文件（遵循POSIX重命名行为）改为返回重命名失败
    • Linux和macOS保持原来的遵循Unix重命名覆盖语义-先删除旧文件再重命名，若旧文件为非空目录则返回错误ENOTEMPTY，符合POSIX rename(2)行为
    • Windows由原来的遵循POSIX行为改为循序Win32 MoveFile默认行为，即重命名冲突时返回ERROR_ALREAD_EXISTS错误，资源管理器会弹出"目标已存在"提示
  6. 通过迅雷直接登录的帐号和通过合作伙伴设备直接登录的帐号，在个人资料页屏蔽修改密码选项，只保留修改邮箱和密码选项
  7. 修复web界面复制到剪贴板按钮在非安全上下文(访问cd2的url为http://且非localhost)下工作不正常的问题
  8. 其它性能改进和bug修复

0.9.9(Web2.1.0.0)
  1. 增加API令牌管理，用户可以创建多个API令牌，第三方应用可以通过用户创建的令牌访问CloudDrive的服务和功能，无需知道CloudDrive的用户名和密码。创建令牌时可以指定允许访问的根目录，有效期，可以为每一项功能设定是否允许访问的权限，包括文件读取、文件写入、文件修改、系统操作、云存储操作、账号操作大项功能等，每格大项功能都分成若干子项目，可以为每个子项目设置权限，具体请参见创建和修改API令牌界面。API文档和开发者指南可以在官网主页访问和下载
